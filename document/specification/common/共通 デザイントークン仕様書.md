## 1. デザイン方針

### 1.1 コンセプト

プレミテのUIは「シネマダーク」をベースとする。動画視聴が主体のサービスとして、サムネイルやコンテンツが主役になるよう、UIクローム（ナビ・ボタン・カード）は背景に溶け込む設計とする。

参考UIとして YouTube シアターモード・Amazon Prime Video を参照している。

### 1.2 カラー使用の原則

| 色 | 用途 |
|----|------|
| 白・グレー系 | UI全般（背景・ボタン・テキスト） |
| 赤（`#e03030`） | ロゴアイコンのみ. それ以外には使用しない |
| アンバー（`#f0a500`） | ★スコア表示のみ. それ以外には使用しない |
| シアングリーン（`#1db37a`） | 「視聴中」ステータスのアクティブ表示のみ |
| スカイブルー（`#38a8f5`） | 「注目上昇中」バッジのみ |
| オレンジレッド（`#bf360c`） | 楽天ブックスボタンのみ |

刺し色は用途を厳格に限定し、多用しない。

## 4. ボタン

ボタンは3段階の優先度で使い分ける。

### 4.1 プライマリボタン（最重要アクション）

「視聴する」「続きから再生」など、ページ内で最も重要な1アクションに使用する。1ページにつき原則1つ。

| 項目 | 値 |
|------|----|
| 背景色 | `#e8e8e8` |
| テキスト色 | `#111111` |
| フォントサイズ | `14px` |
| フォントウェイト | `500` |
| 角丸 | `7px` |
| パディング | `9px 22px` |

```css
background: #e8e8e8;
color: #111111;
font-size: 14px;
font-weight: 500;
border-radius: 7px;
padding: 9px 22px;
border: none;
```

### 4.2 セカンダリボタン（重要アクション）

「マイリストに追加」「前へ」「次へ」「シアター」「連続再生」など操作系に使用する。

| 項目 | 値 |
|------|----|
| 背景色 | `#252525` |
| テキスト色 | `#e0e0e0` |
| ボーダー | `0.5px solid #3a3a3a` |
| フォントサイズ | `13px` |
| フォントウェイト | `500` |
| 角丸 | `7px` |
| パディング | `8px 14px`（操作系） / `10px`（幅100%のアクション系） |

```css
background: #252525;
color: #e0e0e0;
font-size: 13px;
font-weight: 500;
border-radius: 7px;
padding: 8px 14px;
border: 0.5px solid #3a3a3a;
```

### 4.3 外部リンクボタン（サードパーティ）

楽天ブックスなど、外部サービスへ誘導するボタン。各サービスのブランドカラーを使用する。

| サービス | 背景色 | テキスト色 |
|---------|--------|-----------|
| 楽天ブックス | `#bf360c` | `#ffffff` |

```css
background: #bf360c;
color: #ffffff;
font-size: 12px;
font-weight: 500;
border-radius: 6px;
padding: 6px 12px;
border: none;
```

## 5. バッジ・ステータス表示

### 5.1 視聴ステータスチップ

レビューセクションの視聴ステータス選択UIに使用する。

#### 非アクティブ状態

```css
background: #1a1a1a;
color: #aaaaaa;
border: 0.5px solid #2e2e2e;
border-radius: 20px;
font-size: 12px;
padding: 5px 12px;
```

#### アクティブ状態（「視聴中」選択時）

「視聴中」選択時のみシアングリーンを使用する。

```css
background: #0d2e2a;
color: #1db37a;
border: 0.5px solid #1db37a;
border-radius: 20px;
font-size: 12px;
padding: 5px 12px;
/* 左端にドットを付与 */
```

ドット仕様：
- サイズ：`5px × 5px`
- 形状：円形（`border-radius: 50%`）
- 色：`#1db37a`
- テキストとの間隔：`5px`

#### アクティブ状態（「視聴中」以外を選択時）

見たい・完走・一時中断・断念のアクティブ色は白系で統一する（刺し色は「視聴中」のみに限定する原則）。ドットは付けない。

```css
background: #252525;
color: #e8e8e8;
border: 0.5px solid #3a3a3a;
border-radius: 20px;
font-size: 12px;
padding: 5px 12px;
```

#### マイリストカード上のステータスバッジ

マイリストのカードに表示する現在ステータスは、上記チップと同じスタイル（アクティブ状態）を使う。クリックでステータス変更ドロップダウン（§13.3）を開く。

### 5.2 注目上昇中バッジ

再生リスト基本情報カードの右上に表示する。表示条件は別途ロジックで定義する。

```css
background: #0a1e2e;
color: #38a8f5;
border: 0.5px solid #38a8f5;
border-radius: 4px;
font-size: 11px;
font-weight: 500;
padding: 3px 8px;
```

表示内容：`↑ 注目上昇中`

## 9. ローディング要素 (Loading)

シネマダークの没入感を損なわないよう、控えめな配色と滑らかなアニメーションを基本とする。

### 9.1 Skeleton Screen（スケルトン）

実コンテンツの読み込み前に表示するプレースホルダー。

| トークン名 | 値 | 用途 |
|-----------|-----|------|
| `color-skeleton-bg` | `#1a1a1a` | スケルトン領域の基本背景色（`color-bg-input`と共通） |
| `color-skeleton-shimmer` | `linear-gradient(90deg, transparent, rgba(255, 255, 255, 0.03), transparent)` | 通過するハイライト（シマー） |
| `animation-skeleton-shimmer` | `1.5s infinite linear` | シマーのアニメーション速度 |

```css
/* 実装イメージ */
.skeleton {
  background-color: #1a1a1a;
  background-image: linear-gradient(90deg, transparent, rgba(255, 255, 255, 0.03), transparent);
  background-size: 200% 100%;
  animation: skeleton-shimmer 1.5s infinite linear;
}

@keyframes skeleton-shimmer {
  from { background-position: 200% 0; }
  to { background-position: -200% 0; }
}
```

### 9.2 Spinner（スピナー）

ボタン内アクションや小規模なデータ更新時に使用する。

| トークン名 | 値 | 用途 |
|-----------|-----|------|
| `color-spinner` | `#aaaaaa` | スピナー動線色（`color-text-tertiary`と共通） |

## 10. フォーム入力要素

テキスト入力・パスワード入力・セレクト・テキストエリアに共通で適用する。

| トークン名 | 値 | 用途 |
|-----------|-----|------|
| `color-input-bg` | `#1a1a1a` | 入力要素背景（`color-bg-input`と共通） |
| `color-input-border` | `#3a3a3a` | 入力要素枠線（`color-border-strong`と共通） |
| `color-input-text` | `#e8e8e8` | 入力文字色（`color-text-primary`と共通） |
| `color-input-placeholder` | `#888888` | プレースホルダー（`color-text-muted`と共通） |
| `color-input-error` | `#e03030` | バリデーションエラー時の枠線・エラーメッセージ文字色 |

```css
background: #1a1a1a;
color: #e8e8e8;
border: 0.5px solid #3a3a3a;
border-radius: 7px;
font-size: 13px;
padding: 9px 12px;
width: 100%;
```

- ラベルは入力要素の上に配置し、`font-size: 12px`・`color: #aaaaaa`（`color-text-tertiary`）とする。
- エラーメッセージは入力要素の直下に `font-size: 12px`・`color: #e03030` で表示する。
- チェックボックス・トグルスイッチはブラウザ標準の `accent-color: #e8e8e8` を指定し、刺し色は使わない。

## 11. インタラクション状態（ホバー・フォーカス・無効）

### 11.1 ホバー

| 対象 | ホバー時 |
|------|---------|
| プライマリボタン | 背景 `#ffffff` |
| セカンダリボタン | 背景 `#2e2e2e` |
| テキストリンク・ナビリンク | 文字色 `#e8e8e8`（`color-text-primary`） |
| カード（クリック可能なもの） | 枠線 `#3a3a3a`（`color-border-strong`） |
| 動画リストアイテム | 背景 `#1c1c1c`（再生中ハイライトと同じ） |

トランジションは `transition: background-color 120ms, color 120ms, border-color 120ms` を基本とする。

### 11.2 フォーカス

キーボード操作時のフォーカス表示は全インタラクティブ要素で共通とする。刺し色は使わない。

```css
outline: 2px solid #3a3a3a;
outline-offset: 2px;
```

マウスクリック時にはフォーカスリングを表示しない（`:focus-visible` のみに適用する）。

### 11.3 無効（disabled）

```css
opacity: 0.4;
cursor: not-allowed;
```

## 12. トースト

操作結果を短時間表示する通知（挙動は「共通 uiコンポーネント フロント 仕様書」§6を参照）。背景はカードと同じダークグレーとし、種別ごとの色は左ボーダーとアイコンにのみ使う。

| 種別 | トークン名 | 値 |
|------|-----------|-----|
| 成功（success） | `color-toast-success` | `#1db37a` |
| エラー（error） | `color-toast-error` | `#e03030` |
| 警告（warning） | `color-toast-warning` | `#f0a500` |
| 情報（info） | `color-toast-info` | `#38a8f5` |

```css
background: #141414;
color: #e8e8e8;
border: 0.5px solid #222222;
border-left: 4px solid var(--color-toast-success); /* 種別で切り替え */
border-radius: 10px;
font-size: 13px;
padding: 12px 16px;
min-width: 280px;
max-width: 420px;
box-shadow: 0 8px 24px rgba(0, 0, 0, 0.5);
```

- 表示位置は画面上部中央、ヘッダー直下（上端から `72px`）。複数件は `8px` 間隔で縦に積み上げる。
- 閉じるボタン「×」は右端に `color-text-muted` で表示する。

## 13. オーバーレイ面（モーダル・ドロワー・ドロップダウン）

| トークン名 | 値 | 用途 |
|-----------|-----|------|
| `color-overlay` | `rgba(0, 0, 0, 0.6)` | モーダル・ドロワー背後のオーバーレイ |
| `color-surface-elevated` | `#141414` | モーダル・ドロワー・ドロップダウンの面（`color-bg-card`と共通） |
| `color-surface-border` | `#222222` | 面の枠線（`color-border-default`と共通） |
| `shadow-elevated` | `0 8px 24px rgba(0, 0, 0, 0.5)` | 面の影（ダーク背景上で面を浮かせる唯一の影） |

### 13.1 モーダル

```css
background: #141414;
border: 0.5px solid #222222;
border-radius: 10px;
padding: 24px;
max-width: 480px;
width: calc(100% - 32px);
box-shadow: 0 8px 24px rgba(0, 0, 0, 0.5);
```

閉じるボタン「×」は右上 `12px` の位置に `color-text-muted` で表示する。

### 13.2 ドロワー

モバイルのハンバーガーメニュー（UIコンポーネント仕様書 §2.7）で使用。左端からスライドインする。

```css
background: #141414;
border-right: 0.5px solid #222222; /* 左からのドロワーのため右側に境界線 */
width: min(300px, 85vw);
height: 100dvh;
padding: 20px;
```

ドロワー内のリンクは `font-size: 14px`・`color: #e8e8e8`・行高 `44px`（タップ領域確保）。グループ間のセパレーターは `border-top: 0.5px solid #1e1e1e`。

### 13.3 ドロップダウン（ユーザーメニュー・ステータス変更・その他▼）

```css
background: #141414;
border: 0.5px solid #222222;
border-radius: 8px;
padding: 6px;
min-width: 180px;
box-shadow: 0 8px 24px rgba(0, 0, 0, 0.5);
```

項目は `font-size: 13px`・`color: #cccccc`・`padding: 8px 10px`・角丸 `6px`。ホバー・キーボード選択中の項目は背景 `#252525`・文字 `#e8e8e8`。

## 14. ヘッダー・ナビゲーション

| 項目 | 値 |
|------|----|

## 15. インジケーター（未読ドット・件数バッジ・タブ）

### 15.1 未読ドット

通知一覧の未読カード、ヘッダーのベルアイコンに使用する。

```css
width: 6px;
height: 6px;
border-radius: 50%;
background: #e03030;
```

ベルアイコン上では右上に重ね、未読件数がある場合はドットの代わりに件数バッジ（`min-width: 16px`・`height: 16px`・`font-size: 10px`・背景 `#e03030`・文字 `#ffffff`・角丸 `8px`）を表示する。99件超は「99+」。

### 15.2 タブの件数バッジ

マイリストのフィルタタブ等に表示する件数。

```css
background: #252525;
color: #aaaaaa;
font-size: 11px;
padding: 1px 6px;
border-radius: 8px;
margin-left: 6px;
```

アクティブなタブでは `color: #e8e8e8`。

### 15.3 タブ（フィルタ）

```css
/* 非アクティブ */
color: #aaaaaa;
font-size: 13px;
padding: 8px 12px;
border-bottom: 2px solid transparent;

/* アクティブ */
color: #e8e8e8;
border-bottom-color: #e8e8e8;
```
