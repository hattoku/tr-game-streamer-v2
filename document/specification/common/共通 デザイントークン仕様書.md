## 1. デザイン方針

### 1.1 コンセプト

プレミテのUIは「シネマダーク」をベースとする。動画視聴が主体のサービスとして、サムネイルやコンテンツが主役になることは変えない。

ただし v1 系の「UIクロームは背景に溶け込む」という方針は v2.0 で改める。フェーズ2.5で v1 のトークンどおりに実装した結果、カード・ボタン・タブが平坦で区別がつかず、ゲームというエンタメを扱うサイトとして物足りないと評価された（2026-09-12、方向性モックアップ4案を比較し「A. クリムゾン」を採用）。v2.0 では **UIクロームは面と奥行きを持って立つ** ものとし、以下の3原則に従う。

1. **黒ベースに白系UI、2色目は足さない。** 面の質感（グラデーション・影・浮き上がり）で豊かさを出し、色数で出さない。
2. **ブランド赤の用途を「ロゴのみ」から「主要アクションと進行」へ広げる。** プライマリボタン・進捗バー・未読ドット・再生中バッジ・サムネイル上の再生ボタンに使う。
3. **奥行きは §16 のエレベーション（面・影・浮き上がり）で作る。** 面ごとに影の段階を決め、ホバーで浮き上がる。グロー（発光）は使わない。

参考UIとして YouTube・Amazon Prime Video を参照している。

### 1.2 カラー使用の原則

| 色 | 用途 |
|----|------|
| 白・グレー系 | UI全般（背景・セカンダリボタン・テキスト・アクティブ表示） |
| 赤（`#e03030`） | ロゴ・プライマリボタン・進捗バー・未読ドット・再生中バッジ・サムネイル上の再生ボタン |
| アンバー（`#f0a500`） | ★スコア表示のみ. それ以外には使用しない |
| シアングリーン（`#1db37a`） | 「視聴中」ステータスのアクティブ表示のみ |
| スカイブルー（`#38a8f5`） | 「注目上昇中」バッジのみ |
| オレンジレッド（`#bf360c`） | 楽天ブックスボタンのみ |

刺し色は用途を厳格に限定し、多用しない。アクティブ表示（タブ下線・ナビ下線・選択中チップ・フォーカス）は白系（`#e8e8e8`）で統一する。

## 4. ボタン

ボタンは4段階の優先度で使い分ける。いずれも `font-family: inherit`、トランジションは §11 に準ずる。

### 4.1 プライマリボタン（最重要アクション）

「再生する」「続きから再生」「アカウント作成」など、ページ内で最も重要な1アクションに使用する。1ページにつき原則1つ。v2.0 でブランド赤の面に変更した。

| 項目 | 値 |
|------|----|
| 背景 | `gradient-primary` |
| テキスト色 | `#ffffff` |
| フォントサイズ | `14px` |
| フォントウェイト | `600` |
| 角丸 | `8px` |
| パディング | `9px 22px`（幅100%のアクション系は `11px 22px`） |
| 影 | `shadow-primary` ＋ 上端ハイライト `inset 0 1px 0 rgba(255, 255, 255, 0.18)` |

```css
background: linear-gradient(180deg, #ea4444 0%, #c92626 100%);
color: #ffffff;
font-size: 14px;
font-weight: 600;
border-radius: 8px;
padding: 9px 22px;
border: none;
box-shadow: 0 4px 14px rgba(224, 48, 48, 0.35), inset 0 1px 0 rgba(255, 255, 255, 0.18);
```

先頭にアイコン（再生三角等）を置く場合、アイコンとテキストの間隔は `6px`。

### 4.2 セカンダリボタン（重要アクション）

「マイリストに追加」「前へ」「次へ」「シアター」「逆順で再生」など操作系に使用する。

| 項目 | 値 |
|------|----|
| 背景 | `linear-gradient(180deg, #2c2c2c 0%, #222222 100%)` |
| テキスト色 | `#e0e0e0` |
| ボーダー | `1px solid color-border-control` |
| フォントサイズ | `13px` |
| フォントウェイト | `500` |
| 角丸 | `8px` |
| パディング | `8px 14px`（操作系） / `10px`（幅100%のアクション系） |
| 影 | `0 2px 6px rgba(0, 0, 0, 0.35)` ＋ 上端ハイライト `inset 0 1px 0 rgba(255, 255, 255, 0.06)` |

```css
background: linear-gradient(180deg, #2c2c2c 0%, #222222 100%);
color: #e0e0e0;
font-size: 13px;
font-weight: 500;
border-radius: 8px;
padding: 8px 14px;
border: 1px solid rgba(255, 255, 255, 0.14);
box-shadow: 0 2px 6px rgba(0, 0, 0, 0.35), inset 0 1px 0 rgba(255, 255, 255, 0.06);
```

#### トグルON状態（逆順で再生・連続再生など、状態を持つセカンダリボタン）

```css
background: rgba(232, 232, 232, 0.10);   /* color-bg-selected */
color: #e8e8e8;
border: 1px solid #e8e8e8;               /* color-border-active */
```

### 4.3 外部リンクボタン（サードパーティ）

楽天ブックスなど、外部サービスへ誘導するボタン。各サービスのブランドカラーを使用する。

| サービス | 背景色 | テキスト色 |
|---------|--------|-----------|
| 楽天ブックス | `#bf360c` | `#ffffff` |

```css
background: #bf360c;
color: #ffffff;
font-size: 12px;
font-weight: 500;
border-radius: 6px;
padding: 6px 12px;
border: none;
```

末尾に外部リンクアイコン（12px）を付ける。

### 4.4 ゴーストボタン（従アクション）

「マイリストから削除」「キャンセル」など、目立たせたくない従アクションに使用する。面を持たないが、ホバーで面が現れる。

```css
background: transparent;
color: #888888;                          /* color-text-muted */
font-size: 13px;
font-weight: 400;
border-radius: 8px;
padding: 8px 12px;
border: 1px solid transparent;
/* ホバー: color #e8e8e8; background rgba(255, 255, 255, 0.06) */
```

横並びのボタン群（チップ・トグル・ゴースト）は `12px` 間隔で並べ、性格の異なるボタンの間には縦線セパレーター（`1px × 18px`、`rgba(255, 255, 255, 0.10)`）を置いて、一体のボタンに見えないようにする。

## 5. バッジ・ステータス表示

### 5.1 視聴ステータスチップ

マイリストカードのステータス表示・ステータス選択UIに使用する。

#### 非アクティブ状態

```css
background: #1a1a1a;
color: #aaaaaa;
border: 1px solid rgba(255, 255, 255, 0.12);   /* color-border-chip */
border-radius: 20px;
font-size: 12px;
padding: 5px 12px;
```

#### アクティブ状態（「視聴中」選択時）

「視聴中」選択時のみシアングリーンを使用する。

```css
background: #0d2e2a;
color: #1db37a;
border: 1px solid #1db37a;
border-radius: 20px;
font-size: 12px;
font-weight: 600;
padding: 5px 12px;
/* 左端にドットを付与 */
```

ドット仕様：
- サイズ：`6px × 6px`
- 形状：円形（`border-radius: 50%`）
- 色：`#1db37a`
- テキストとの間隔：`6px`

#### アクティブ状態（「視聴中」以外を選択時）

見たい・完走・一時中断・断念のアクティブ色は白系で統一する（刺し色は「視聴中」のみに限定する原則）。ドットは付けない。

```css
background: rgba(232, 232, 232, 0.10);   /* color-bg-selected */
color: #e8e8e8;
border: 1px solid #e8e8e8;               /* color-border-active */
border-radius: 20px;
font-size: 12px;
font-weight: 600;
padding: 5px 12px;
```

#### マイリストカード上のステータスバッジ

マイリストのカードに表示する現在ステータスは、上記チップと同じスタイル（アクティブ状態）を使い、右に `▾` シェブロン（12px、`color-text-muted`）を添える。クリックでステータス変更ドロップダウン（§13.3）を開く。

### 5.2 注目上昇中バッジ

再生リスト基本情報カードの右上に表示する。表示条件は別途ロジックで定義する。

```css
background: #0a1e2e;
color: #38a8f5;
border: 1px solid #38a8f5;
border-radius: 4px;
font-size: 11px;
font-weight: 500;
padding: 3px 8px;
```

表示内容：`↑ 注目上昇中`

### 5.3 再生中バッジ

サムネイルの左上に重ねる。動画リストの現在再生中・マイリストカードの再生中表示に使う。

```css
background: #e03030;
color: #ffffff;
font-size: 10px;
font-weight: 600;
border-radius: 4px;
padding: 2px 7px;
```

## 6. カード・コンテナ

### 6.1 標準カード

再生リストカード・マイリストカード・再生リスト詳細の各セクション（基本情報・チャンネル情報・ゲーム情報など）に使用する。v2.0 で面のグラデーション・影・ホバーの浮き上がりを追加した。

```css
background: linear-gradient(180deg, #191919 0%, #131313 100%);
border: 1px solid rgba(255, 255, 255, 0.07);   /* color-border-card */
border-radius: 12px;
padding: 18px;                                  /* サムネイルを上端いっぱいに置くカードは 0 にし、本文側に 12px 14px 14px */
box-shadow: 0 6px 18px rgba(0, 0, 0, 0.45);     /* shadow-card（§16） */
overflow: hidden;
```

#### クリック可能なカードのホバー

```css
transform: translateY(-3px);
border-color: rgba(255, 255, 255, 0.14);        /* color-border-card-hover */
box-shadow: 0 14px 32px rgba(0, 0, 0, 0.6);     /* shadow-card-hover（§16） */
transition: transform 120ms, border-color 120ms, box-shadow 120ms;
```

### 6.2 カード内セパレーター

```css
border-top: 1px solid rgba(255, 255, 255, 0.06);   /* color-border-divider */
```

### 6.3 動画リストアイテム（再生中ハイライト）

```css
background: #1c1c1c;
```

再生中の動画のサムネイルには §5.3 の再生中バッジを左上に重ねる。

### 6.4 視聴進捗バー

サムネイル直下に表示する細い横線。

| 項目 | 値 |
|------|----|
| 高さ | 動画リスト内 `2px`／マイリストカードの子エリア `3px` |
| 未視聴部分 | `#333333` |
| 視聴済み部分 | `#e03030`（YouTube準拠） |
| 角丸 | `2px`（サムネイルの角丸と揃える場合は下側のみ） |
| 配置 | サムネイル直下（動画リストは `margin-top: 2px`、子エリアはサムネイルに密着） |

### 6.5 サムネイル

カード上端・リスト内のサムネイルに共通で適用する。

| 項目 | 値 |
|------|----|
| アスペクト比 | 16:9 |
| 下部オーバーレイ | 高さ 46%、`linear-gradient(180deg, rgba(0,0,0,0) 0%, rgba(0,0,0,0.65) 100%)`。話数バッジ・文字を読みやすくする |
| 話数バッジ | 右下 `8px`。背景 `rgba(0, 0, 0, 0.72)`、文字 `#e8e8e8`、`11px`、角丸 `4px`、パディング `2px 7px`。表記は **「N話」**（「全N話」とはしない。更新中の再生リストがあるため） |
| ホバー時の再生ボタン | 中央に `44px` 円形、背景 `gradient-primary`、影 `shadow-primary`、白い再生三角 `20px`。クリック可能なカードのホバー時のみ表示 |
| 再生中バッジ | 左上 `8px`（§5.3） |

### 6.6 子エリア（親子カード）

マイリストカードの「最後に再生した動画」など、カードの中で親（再生リスト）と子（動画）を分けて見せる領域。

```css
border-top: 1px solid rgba(255, 255, 255, 0.06);   /* color-border-divider */
background: rgba(255, 255, 255, 0.03);             /* color-bg-child */
padding: 12px 18px 14px;
```

子エリアの先頭に `11px`・`color-text-muted` のラベル（「最後に再生」）を置く。

## 9. ローディング要素 (Loading)

シネマダークの没入感を損なわないよう、控えめな配色と滑らかなアニメーションを基本とする。

### 9.1 Skeleton Screen（スケルトン）

コンテンツの読み込み中に、実コンテンツと同じレイアウトでプレースホルダーを表示する。

| トークン名 | 値 | 用途 |
|-----------|-----|------|
| `color-skeleton-bg` | `#1a1a1a` | スケルトンの基本背景色 |
| `color-skeleton-highlight` | `rgba(255, 255, 255, 0.03)` | シマー（光沢）の色 |

```css
background-color: #1a1a1a;
background-image: linear-gradient(90deg, transparent, rgba(255, 255, 255, 0.03), transparent);
background-size: 200% 100%;
animation: skeleton-shimmer 1.5s infinite linear;
border-radius: 6px;
```

```css
@keyframes skeleton-shimmer {
  from { background-position: 200% 0; }
  to { background-position: -200% 0; }
}
```

- 実コンテンツと同じサイズ・角丸・余白で置く。カードのスケルトンはカードと同じ面（§6.1）の上に置く。
- テキスト行は実コンテンツよりやや短く（幅 60〜80%）、複数行では末尾を揃えない。

### 9.2 Spinner（スピナー）

ボタン内のアクション実行中、無限スクロールの末尾など、小さな領域の読み込みに使う。

| トークン名 | 値 | 用途 |
|-----------|-----|------|
| `color-spinner` | `#aaaaaa` | スピナーの色 |

- サイズ: 標準 `24px`、ボタン内 `14px`。線幅 `2px`。
- 1周 `0.8s` の線形回転。

## 10. フォーム入力要素

テキスト入力・パスワード入力・セレクト・テキストエリアに共通で適用する。

| トークン名 | 値 | 用途 |
|-----------|-----|------|
| `color-input-bg` | `#1a1a1a` | 入力要素背景（`color-bg-input`と共通） |
| `color-input-border` | `rgba(255, 255, 255, 0.14)` | 入力要素枠線（`color-border-control`と共通） |
| `color-input-text` | `#e8e8e8` | 入力文字色（`color-text-primary`と共通） |
| `color-input-placeholder` | `#888888` | プレースホルダー（`color-text-muted`と共通） |
| `color-input-error` | `#e03030` | バリデーションエラー時の枠線・エラーメッセージ文字色 |

```css
background: #1a1a1a;
color: #e8e8e8;
border: 1px solid rgba(255, 255, 255, 0.14);
border-radius: 7px;
font-size: 13px;
padding: 9px 12px;
width: 100%;
box-shadow: inset 0 1px 2px rgba(0, 0, 0, 0.5);   /* 面より一段沈んで見せる */
```

- フォーカス時: `border-color: #e8e8e8`・`box-shadow: 0 0 0 3px rgba(232, 232, 232, 0.10)`（§11.2 のアウトラインは使わず、枠線とリングで表現する）。
- ラベルは入力要素の上に配置し、`font-size: 12px`・`color: #aaaaaa`（`color-text-tertiary`）とする。
- エラーメッセージは入力要素の直下に `font-size: 12px`・`color: #e03030` で表示する。
- **セレクト（`<select>`）はブラウザ標準のドロップダウンを使わない。** 表示部は入力要素と同じ面にシェブロンを添え、開いた一覧は §13.3 のドロップダウンで描画する（ブラウザ標準の一覧はOSのダーク配色と混ざり文字が読めなくなるため）。
- チェックボックス・トグルスイッチはブラウザ標準の `accent-color: #e8e8e8` を指定し、刺し色は使わない。

## 11. インタラクション状態（ホバー・フォーカス・無効）

### 11.1 ホバー

| 対象 | ホバー時 |
|------|---------|
| プライマリボタン | `filter: brightness(1.08)` ＋ `transform: translateY(-1px)` |
| セカンダリボタン | 背景 `linear-gradient(180deg, #343434 0%, #282828 100%)` |
| ゴーストボタン | 文字 `#e8e8e8`・背景 `rgba(255, 255, 255, 0.06)` |
| テキストリンク・ナビリンク | 文字色 `#e8e8e8`（`color-text-primary`） |
| カード（クリック可能なもの） | §6.1「クリック可能なカードのホバー」（浮き上がり・枠線・影・再生ボタン） |
| 動画リストアイテム | 背景 `#1c1c1c`（再生中ハイライトと同じ） |
| タグ | 背景 `rgba(255, 255, 255, 0.10)`・文字 `#e8e8e8` |

トランジションは `transition: background-color 120ms, color 120ms, border-color 120ms, transform 120ms, box-shadow 120ms` を基本とする。

### 11.2 フォーカス

キーボード操作時のフォーカス表示は全インタラクティブ要素で共通とする。刺し色は使わない。

```css
outline: 2px solid #e8e8e8;
outline-offset: 2px;
```

マウスクリック時にはフォーカスリングを表示しない（`:focus-visible` のみに適用する）。入力要素は §10 のフォーカス表現を優先する。

### 11.3 無効（disabled）

```css
opacity: 0.4;
cursor: not-allowed;
```

## 12. トースト

操作結果を短時間表示する通知（挙動は「共通 uiコンポーネント フロント 仕様書」§6を参照）。背景は浮遊面（§13）とし、種別ごとの色は左ボーダーとアイコンにのみ使う。

| 種別 | トークン名 | 値 |
|------|-----------|-----|
| 成功（success） | `color-toast-success` | `#1db37a` |
| エラー（error） | `color-toast-error` | `#e03030` |
| 警告（warning） | `color-toast-warning` | `#f0a500` |
| 情報（info） | `color-toast-info` | `#38a8f5` |

```css
background: linear-gradient(180deg, #202020 0%, #171717 100%);
color: #e8e8e8;
border: 1px solid rgba(255, 255, 255, 0.12);
border-left: 4px solid var(--color-toast-success); /* 種別で切り替え */
border-radius: 10px;
font-size: 13px;
padding: 12px 16px;
min-width: 280px;
max-width: 420px;

```

- 閉じるボタン「×」は右端に `color-text-muted` で表示する。

```css
background: linear-gradient(180deg, #202020 0%, #171717 100%);
```

ドロワー内のリンクは `font-size: 14px`・`color: #e8e8e8`・行高 `44px`（タップ領域確保）。グループ間のセパレーターは `border-top: 1px solid rgba(255, 255, 255, 0.06)`。

### 13.3 ドロップダウン（ユーザーメニュー・ステータス変更・ソート・その他▼）

```css
background: linear-gradient(180deg, #202020 0%, #171717 100%);

border-radius: 10px;
padding: 6px;
min-width: 180px;
box-shadow: 0 12px 32px rgba(0, 0, 0, 0.6);
```

- 項目は `font-size: 13px`・`color: #cccccc`・`padding: 8px 10px`・角丸 `6px`。
- ホバー・キーボード選択中の項目は背景 `rgba(255, 255, 255, 0.06)`・文字 `#e8e8e8`。
- **現在の値**（ステータス変更・ソートで選択中の項目）は背景 `rgba(232, 232, 232, 0.10)`・文字 `#e8e8e8` とし、右端にチェックアイコン（12px）を置く。

## 15. インジケーター（未読ドット・件数バッジ・タブ）

### 15.1 未読ドット

通知一覧の未読カード、ヘッダーのベルアイコンに使用する。

```css
width: 7px;
height: 7px;
border-radius: 50%;
background: #e03030;
box-shadow: 0 0 0 2px #0f0f0f;   /* ベルアイコン上で線と重なっても見えるよう背景色の縁取り */
```

ベルアイコン上では右上に重ね、未読件数がある場合はドットの代わりに件数バッジ（`min-width: 16px`・`height: 16px`・`font-size: 10px`・背景 `#e03030`・文字 `#ffffff`・角丸 `8px`）を表示する。99件超は「99+」。

### 15.2 タブの件数バッジ

マイリストのフィルタタブ等に表示する件数。ピル形状。

```css
display: inline-flex;
align-items: center;
justify-content: center;
min-width: 20px;
height: 18px;
padding: 0 6px;
border-radius: 9px;
background: rgba(255, 255, 255, 0.06);
color: #888888;
font-size: 11px;
font-weight: 600;
margin-left: 6px;
```

アクティブなタブでは背景 `rgba(232, 232, 232, 0.10)`・文字 `#e8e8e8`。

### 15.3 タブ（フィルタ）

タブ列全体の下線は `1px solid rgba(255, 255, 255, 0.08)`。タブ列の右端にソートセレクト（§10）を置く場合は下線の上に `8px` 浮かせる。

```css
font-weight: 600;
```

## 16. 奥行き・演出（エレベーション）

v2.0 で新設。面を3段階に分け、段階ごとに影を固定する。面の質感は「上端がわずかに明るいグラデーション＋1px の半透明白の枠＋影」の組み合わせで作る。

### 16.1 面の3段階

| 段階 | 対象 | 面 | 枠 | 影トークン | 値 |
|------|------|----|----|-----------|-----|
| 0. フラット | ページ背景に直接置くテキスト・見出し・動画リスト・タブ列 | `color-bg-base` | なし（区切りは `color-border-divider`／`color-border-tabs`） | なし | — |
| 1. カード | 再生リストカード・マイリストカード・詳細ページの各セクション・ボトムタブバー | `#191919 → #131313` | `color-border-card` | `shadow-card` | `0 6px 18px rgba(0, 0, 0, 0.45)` |
| 2. 浮遊面 | モーダル・ドロワー・ドロップダウン・トースト | `#202020 → #171717` | `color-surface-border` | `shadow-elevated` | `0 12px 32px rgba(0, 0, 0, 0.6)` |

補助の影:

| トークン名 | 値 | 用途 |
|-----------|-----|------|
| `shadow-card-hover` | `0 14px 32px rgba(0, 0, 0, 0.6)` | クリック可能なカードのホバー |
| `shadow-control` | `0 2px 6px rgba(0, 0, 0, 0.35)` | セカンダリボタン |
| `shadow-primary` | `0 4px 14px rgba(224, 48, 48, 0.35)` | プライマリボタン・再生ボタン・ロゴ |
| `highlight-top` | `inset 0 1px 0 rgba(255, 255, 255, 0.06)`（プライマリは `0.18`） | ボタン上端のハイライト |

### 16.2 動き

| 対象 | 動き |
|------|------|
| クリック可能なカード | ホバーで `translateY(-3px)`、枠線と影を1段強く、サムネイル中央に再生ボタン（§6.5） |
| プライマリボタン | ホバーで `translateY(-1px)` ＋ `brightness(1.08)` |
| その他 | 色・枠線の変化のみ（`120ms`） |

### 16.3 やらないこと

- **グロー（発光）を使わない。** 影は黒のみ、赤い影はプライマリ面にだけ使う。
- **2色目を足さない。** アクティブ表示・強調は白系で行う（§1.2）。
- **グラデーションを強くしない。** 面の上端と下端の差は明度 6 段階（`#191919` と `#131313` 程度）まで。背景全体へのグラデーションは使わない。
- **サムネイルより目立つクロームを作らない。** カードの面はサムネイルより暗く、影はサムネイルに掛からない。
