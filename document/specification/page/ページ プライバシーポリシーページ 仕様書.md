## 1. 概要

> **実装状況（2026-10-14、フェーズ7ステップ7-1）**: `/privacy` を実装済み。本文は未整備のため「内容は工事中です」の暫定表示（`components/layout/UnderConstruction.tsx`）。アカウント作成フォームの同意文から別タブでリンクしている。 §4 の本文は未整備。

プライバシーポリシーページは、プレミテにおける個人情報の取り扱いを掲載するページである。

プライバシーポリシーの本文は後日整備する。本仕様書では、ページの存在とアクセス導線を定義することを目的とする。

本文には以下の事項を含めることとする（詳細文面は後日整備）。

| 記載事項 | 概要 |
|---------|------|
| 収集する個人情報 | アカウント登録時に取得するメールアドレス |
| 利用目的 | アカウント認証、サービス運営に関する連絡 |
| Google Analytics 4（GA4）の利用 | アクセス解析を目的としてGA4を使用しており、Cookieおよびブラウザ識別子を通じた行動データを収集することを明示する |
| Cookieの利用 | Firebase AuthenticationによるセッションCookieを使用することを明示する |
| 第三者提供 | 原則として第三者への提供は行わない旨 |
| 問い合わせ窓口 | 個人情報に関する問い合わせ先 |
| YouTube API サービスの利用（v1.3） | 本サービスが YouTube API サービス（YouTube Data API・埋め込みプレーヤー）を使っていることを明示する（Developer Policies III.A.2.b） |
| Google のプライバシーポリシーへの言及（v1.3） | Google プライバシーポリシー（https://policies.google.com/privacy 。規約の原文は http://www.google.com/policies/privacy を指定）へのリンク（III.A.2.c） |
| 埋め込みプレーヤーによる情報の取得（v1.3） | YouTube の埋め込みプレーヤーで再生すると、YouTube（Google）が Cookie 等で視聴の情報を取得しうること（III.E.4.i。自動再生ではページを開いた時点で取得が始まりうる） |
| 利用者の情報の扱い（v1.3） | 取得・保存・利用する利用者の情報（メールアドレス、視聴記録・マイリスト・レビュー、お問い合わせと添付画像など）と、その利用目的・共有先を分かりやすく説明する（III.A.2.d） |
| 削除の求め（v1.3） | 利用者が自分のデータの削除を求める方法（退会・お問い合わせ）。YouTube API データについては求めから7日以内に消す（III.E.4.g） |

> **v1.3（2026-11-01）**: 上の5行はリブランディング検討 項目9・11 で確認した YouTube API サービス規約の要件。プライバシーポリシーは、機能を使う前に同意を得られるようにし、いつでも目立つ場所から開けるようにする（III.A.2.a。アカウント作成時の同意文 §3.2 とフッターのリンク §3.1 で満たす）。出典: YouTube API Services Developer Policies（https://developers.google.com/youtube/terms/developer-policies）。2026-11-01 に確認。本文を書くときに原文で最新の文面を確かめること。

## 3. 流入導線

### 3.1 フッターからの導線

全ページ共通のフッターにリンクを常設する。

| 項目 | 内容 |
|------|------|
| 表示条件 | ログイン・未ログイン問わず常時表示 |
| リンク文言 | 「プライバシーポリシー」 |
| 配置位置 | フッター内のリンク群に配置 |

### 3.2 アカウント登録フローからの導線

アカウント作成フォームに、プライバシーポリシーへの同意文を設置する。

| 項目 | 内容 |
|------|------|
| 配置位置 | 「アカウントを作成する」ボタンの直上 |
| 表示文言 | 「アカウントを作成することで、[利用規約]および[プライバシーポリシー]に同意したものとみなします。」 |
| リンク | 「プライバシーポリシー」部分をリンクとし、クリックでプライバシーポリシーページへ遷移する |
| 遷移方式 | 別タブで開く（`target="_blank"`） |

> ソーシャルログイン（Google・X）経由でのアカウント作成にも同様の同意文を表示する。各プロバイダのソーシャルログインボタンの直上に配置する。
