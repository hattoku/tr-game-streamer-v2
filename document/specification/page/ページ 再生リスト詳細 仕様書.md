## 概要

### 目的

再生リスト（ゲーム実況シリーズ）の詳細情報を、ユーザーが効率的に把握できるページレイアウト・UI構成を提供する。動画プレーヤーを中心に、再生リストの基本情報、配信者情報、ゲーム情報を有機的に配置し、ユーザーの導線を最適化する。

### スコープ

- ページ全体のレイアウト・2カラム構成
- ページ内各セクションの配置順序と役割
- 各セクションの表示要素と表示形式
- ページ上のセクション間の相互作用（シアターモード時を含む）
- レスポンシブ対応（PC / モバイル）

### 非スコープ

- YouTube埋め込みプレーヤーの技術実装（別仕様書）
- 動画リストの詳細表示仕様（別仕様書）
- 再生制御機能の動作仕様（別仕様書）
- レビュー投稿セクションの詳細仕様（別仕様書）

## アクセス条件・URL

### アクセス権限

| ユーザー状態 | アクセス可否 | 備考 |
|------------|------------|------|
| 未ログイン | ✅ アクセス可能 | 閲覧・視聴は可能。レビュー投稿・マイリスト登録はログイン必須 |
| ログイン済みユーザー | ✅ アクセス可能 | 全機能利用可能 |

### ページURL

| 項目 | 内容 |
|------|------|
| URL | `/playlists/[playlistId]` |
| ヘッダーナビゲーション | 常に表示（ログイン状態を問わず） |

## 基本情報セクション

### 概要

再生リストの基本的な情報（タイトル、評価、ユーザー数、タグ）をコンパクトに表示するセクション。ユーザーが「このシリーズの信頼度」「どの程度のユーザーに視聴されているか」を素早く判断できるよう設計。参照元URL（YouTubeの元の再生リストへのリンク）は動画リストセクションに配置する（「動画プレーヤー仕様書」参照）。

### 表示順序（上から下へ）

1. 再生リストのタイトル
2. スコア、マイリスト数、レビュー数
3. 付与されたタグ

### 各項目の仕様

| 項目 | 詳細 |
|------|------|
| 再生リストのタイトル | 公式タイトル。長い場合は折り返して全文表示（省略しない） |
| スコア | 信頼度加重平均によるシリーズスコア。表示仕様は信頼度スコアリングシステム仕様書を参照 |
| マイリスト数 | このシリーズをマイリストに登録したユーザー数（数値表示） |
| レビュー数 | 投稿されたレビューの総数（数値表示） |
| タグ | この再生リストに付与されたタグ（バッジ形式で複数表示）。行頭に「タグ」ラベルを常時表示し、タグ編集アイコンが何に対する操作かを明示する（ゲームタイトル詳細仕様書 §8.2準拠） |
| タグ編集アイコン | タグ一覧の末尾に隣接して表示。表示条件はログイン済みユーザーのみ。クリックでタグ編集モーダルを開く（詳細はゲームタイトル詳細仕様書 第8章を参照） |

### 配置イメージ

```
┌─────────────────────────────────┐
│ 再生リストのタイトル             │
│ （長い場合は折り返して全文表示） │
│                                 │
│ ★★★★★ 4.5 / 5                  │
│ マイリスト: 234 | レビュー: 89   │
│                                 │
│ タグ [ジャンル1] [ジャンル2] ✎   │
└─────────────────────────────────┘
```

> タグが0件の場合、ログイン済みユーザーには鉛筆アイコンの代わりに「＋ タグを追加」チップを表示する
> （未ログインの場合はタグ行自体を非表示にする）。

## レビュー投稿セクション

### 概要

ユーザーが再生リストに対して星評価・視聴ステータス・コメントを投稿・閲覧するセクション。

**詳細な仕様はすべて「プレミテ レビュー投稿機能 仕様書」を参照すること。**

### 表示位置

| レイアウト | 配置場所 |
|-----------|---------|
| PC版 | 左カラムの、ヒーローセクションの下 |
| モバイル版 | 動画リストの下、ゲーム情報セクションの上 |

### セクション構成

レビュー投稿セクションは以下の3つのサブセクションで構成される。視聴ステータス記録UIを先に、レビュー投稿UIを後に配置する。

| # | サブセクション名 | 概要 |
|---|----------------|------|
| 1 | この再生リストに対して視聴ステータスを記録する | ログイン済みユーザーが視聴ステータスを選択・変更するUI。マイリスト登録を兼ねる |
| 2 | この再生リストに対してレビューする | ログイン済みユーザーが星評価・コメントを投稿・管理するUI |
| 3 | この再生リストに対してのレビュー一覧 | 他ユーザーのレビューをカード形式で一覧表示するUI |

> 基本情報セクションには視聴ステータス・マイリスト登録の操作UIを重複して置かない（マイリスト登録の入口はこのセクションに一本化する）。詳細は「プレミテ レビュー投稿機能 仕様書」を参照すること。

## 配信者情報セクション

### 概要

再生リストを投稿した配信者（YouTubeチャンネル）の基本情報を表示するセクション。ユーザーが同じ配信者の他の実況シリーズへ自然に導線をたどれるよう設計。

### 表示位置

| レイアウト | 配置場所 |
|-----------|---------|
| PC版 | 右カラムの、基本情報セクションの下、動画リストの上 |
| モバイル版 | 基本情報セクションの下、動画リストの上 |

### 表示レイアウト

```
┌────────────────────────────────┐
│  ⚬ チャンネルアイコン（円形）    │
│                                │
│  チャンネル名                   │
│                                │
│  [    他の再生リストを見る  ›   ]│
└────────────────────────────────┘
```

### 表示要素の仕様

| 項目 | 詳細 |
|------|------|
| チャンネルアイコン | YouTubeから取得した円形のチャンネルアイコン画像 |
| チャンネル名 | 実況者のYouTubeチャンネル名 |
| 他の再生リストを見るボタン | チャンネル詳細ページへの内部リンク。カード幅いっぱいのセカンダリボタン（共通 デザイントークン仕様書 §4.2）で、文言の右に右向きシェブロンアイコンを置く |

### クリック動作

| 要素 | クリック動作 |
|------|------------|
| チャンネルアイコン | チャンネル詳細ページ（`/channels/[channelId]`）へ遷移 |
| チャンネル名 | チャンネル詳細ページ（`/channels/[channelId]`）へ遷移 |
| 他の再生リストを見るボタン | チャンネル詳細ページ（`/channels/[channelId]`）へ遷移 |

## ゲーム情報セクション

### 概要

再生リストに紐づくゲームタイトルの基本情報をコンパクトに表示するセクション。右カラムが縦に伸びすぎないよう、パッケージ画像（小）を左、タイトル・ジャンル・テーマ・楽天ブックスボタンを右に置く**横並びコンパクト構成**とし、その下にタグと導線リンクを置く。楽天ブックスへのアフィリエイト導線と、ゲームタイトル詳細ページへの導線を設ける。

再生リストにゲームタイトルが紐づいていない（`gameId` が null、または参照先の `games` ドキュメントが存在しない）場合は、セクション自体を表示しない。

### 表示位置

| レイアウト | 配置場所 |
|-----------|---------|
| PC版 | 右カラムの、動画リストの下（右カラムの最後） |
| モバイル版 | レビュー投稿セクションの下（ページ最後、フッターの前） |

### 表示レイアウト

```
┌────────────────────────────────┐
│  ゲーム                         │
│  ┌──────┐  ゲームタイトル名      │
│  │パッケ│  ジャンル：RPG         │
│  │ージ  │  テーマ：冒険 / ダンジョン│
│  │画像  │  [楽天ブックスで見る ↗] │
│  └──────┘                      │
│                                │
│  タグ [タグ] [タグ] [タグ]      │
│                                │
│  [このゲームの再生リストを見る ›]│
└────────────────────────────────┘
```

### 表示要素の仕様

| 項目 | 詳細 |
|------|------|
| ゲームタイトル名 | DBに登録されたゲームタイトル名。パッケージ画像の右に配置。最大2行、超過時は省略記号（…）で切り捨て |
| パッケージ画像 | 楽天ブックスAPIから取得したゲームパッケージ画像（アスペクト比 3:4、縦長）。セクション左側に幅96pxで表示。未取得の場合はプレースホルダー（アイコン）を表示 |
| 楽天ブックスで見るボタン | パッケージ画像の右、ジャンル・テーマの下に配置。楽天ブックス商品詳細ページへのアフィリエイトリンク（別タブ）。`games.rakutenUrl` が未登録の場合は表示しない |
| ジャンル | DBのジャンルマスタから取得（`games.genreName`）。ゲームタイトルのジャンルは1つのため単一表示（例：「RPG」）。未設定の場合は行ごと非表示 |
| テーマ | DBのテーママスタから取得。複数の場合は「/」区切りで表示（例：「冒険 / ダンジョン」） |
| タグ | このゲームタイトルに付与されたタグをバッジ形式で表示。表示優先順位は編集不可タグ優先。閲覧のみでタグ編集アイコンは置かない（編集はゲームタイトル詳細ページで行う）。0件の場合はタグ行を表示しない |
| このゲームの再生リストを見るボタン | ゲームタイトル詳細ページへの内部リンク。配信者情報セクションの「他の再生リストを見る」と同じ、カード幅いっぱいのセカンダリボタン＋右向きシェブロンアイコン |

### クリック動作

| 要素 | クリック動作 |
|------|------------|
| ゲームタイトル名 | ゲームタイトル詳細ページ（`/games/[gameId]`）へ遷移 |
| パッケージ画像 | 楽天ブックス商品詳細ページ（アフィリエイトリンク）へ別タブで遷移（`rakutenUrl` 未登録時はリンクなし） |
| 楽天ブックスで見るボタン | 楽天ブックス商品詳細ページ（アフィリエイトリンク）へ別タブで遷移 |
| タグ | 「ゲームタイトルから探す」ページへ遷移し、クリックしたタグが検索条件として適用された状態で表示する |
| このゲームの再生リストを見るボタン | ゲームタイトル詳細ページ（`/games/[gameId]`）へ遷移 |

### 楽天ブックスアフィリエイトリンク

| 項目 | 仕様 |
|------|------|
| ボタン文言 | 「楽天ブックスで見る ↗」 |
| 遷移先 | 楽天ブックス商品詳細ページ（アフィリエイトリンク） |
| 開き方 | 別タブ（`target="_blank"`） |
| アフィリエイトキー | 環境変数 `NEXT_PUBLIC_RAKUTEN_AFFILIATE_ID` を表示時に `games.rakutenUrl` へ付与する（ゲームタイトル詳細ページと共通。未設定時は元の商品URLのまま） |

## スマートフォン対応

### ブレークポイント

「共通 ページレイアウト 仕様書 §2」の定義に準ずる。

| 区分 | 画面幅 |
|------|--------|
| PC版（2カラム） | 768px以上 |
| モバイル版（シングルカラム） | 767px以下 |

### モバイル版のセクション順序

PC版と異なり、モバイル版では以下の順序で縦積みで表示する。

| 順序 | セクション |
|------|----------|
| 1 | ヘッダー |
| 2 | ヒーローセクション（プレーヤー・コントローラボタン） |
