## 3. 流入導線

### 3.1 フッターからの導線

全ページ共通のフッターにリンクを常設する。

| 項目 | 内容 |
|------|------|
| 表示条件 | ログイン・未ログイン問わず常時表示 |
| リンク文言 | 「利用規約」 |
| 配置位置 | フッター内のリンク群に配置 |

### 3.2 アカウント登録フローからの導線

アカウント作成フォームに、利用規約への同意文を設置する。

| 項目 | 内容 |
|------|------|
| 配置位置 | 「アカウントを作成する」ボタンの直上 |
| 表示文言 | 「アカウントを作成することで、[利用規約]および[プライバシーポリシー]に同意したものとみなします。」 |
| リンク | 「利用規約」部分をリンクとし、クリックで利用規約ページへ遷移する |
| 遷移方式 | 別タブで開く（`target="_blank"`） |

> ソーシャルログイン（Google・X）経由でのアカウント作成にも同様の同意文を表示する。各プロバイダのソーシャルログインボタンの直上に配置する。

### 4.1 本文に必ず入れる事項（v1.3、リブランディング検討 項目9・11）

プレミテは YouTube Data API と YouTube の埋め込みプレーヤー（YouTube API サービス）を使うため、本文（7-1）に次を入れる。

| 事項 | 内容 | 根拠 |
|---|---|---|
| YouTube の利用規約へのリンク | 「本サービスは YouTube API サービスを利用しています。本サービスを利用することで、YouTube の利用規約（https://www.youtube.com/t/terms）に同意したものとみなします」の趣旨と、YouTube の利用規約へのリンク | Developer Policies III.A.1（APIクライアントの利用規約で、ユーザーが YouTube の利用規約に拘束されることを示し、リンクを出す） |
| YouTube が推奨・承認していると誤解させない | 本サービスは運営者が独自に提供するもので、掲載している動画・チャンネル・再生リストは YouTube 上で公開されているものである旨。YouTube のロゴ・名称を、提携や推奨を思わせる形では使わない。「YouTube・掲載チャンネルと提携していません」という明記まではしない（項目9 決定 C） | III.F.2（YouTube が出典であることを明示し、YouTube 以外のものを YouTube 由来に見せない）、III.D.1・III.I（自分のサービスを偽らない・誤解させない） |
| 掲載の方針と掲載停止の窓口 | 掲載するチャンネルは、実況者本人・公式のチャンネルを運営が確認して載せること（品質を保証するものではない）。実況者・事務所から掲載を外したいとの申し出があればチャンネル単位で速やかに掲載を止めること。窓口はお問い合わせ（種別「チャンネルの掲載について」）。実況者・事務所の方へのページ（`/creators`）にも案内する | 項目8・9 決定 |
| プレミテ独自の評価 | スコア・レビュー・ランキングはプレミテ利用者の評価であり、YouTube の評価・数値ではないこと | III.E.4.h（YouTube 以外の指標を API データと並べて出すときは YouTube 由来でないと分かるようにする） |

> 出典: YouTube API Services Developer Policies（https://developers.google.com/youtube/terms/developer-policies）。2026-11-01 に確認。本文を書くときに原文で最新の文面を確かめること。
