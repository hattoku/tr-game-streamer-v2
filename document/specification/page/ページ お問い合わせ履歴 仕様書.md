## 1. 概要

本仕様書は、ログイン済みユーザーが自分のお問い合わせ履歴とスレッドを確認・返信できる、お問い合わせ履歴ページ（`/contact/history`）の仕様を定義する。

### 1.1 実装状況（2026-10-24、フェーズ7ステップ7-3-2）

一覧（`/contact/history`）とスレッド詳細（`/contact/history/[inquiryId]`）を実装済み。決定事項（ユーザー決定を含む）:

| 項目 | 実装 |
|------|------|
| スレッド詳細のURL | 本仕様に定めが無かったため `/contact/history/[inquiryId]` を新設した（ページ一覧仕様書 #19-1）。一覧の行・返信通知からここへ遷移する。本人以外のお問い合わせ・存在しないIDは 404 |
| データの取得 | 対応メモ（`operatorMemo`）を渡さないため、クライアントから Firestore を直接読まず、本人専用の API（`GET /api/inquiries`・`GET /api/inquiries/[inquiryId]`、Admin SDK）が公開してよい項目だけを返す（管理 お問い合わせ管理仕様書 §1.1、2026-10-24 ユーザー決定）。`firestore.rules` で本人の `inquiries`・`messages` 直接読み取りを禁じた。リアルタイム更新はせず、自分の送信・再オープン後に取り直す |
| 対象 | 自分がログイン中に送ったお問い合わせのみ。ゲストとして送ったもの（スレッドが無い）は表示しない |
| 未読インジケーター（§3） | 管理者の最後の返信日時（`lastAdminMessageAt`）が、本人が最後にスレッドを開いた日時（`userLastReadAt`）より新しいときに表示する。スレッド詳細を開いた時点で既読にし、そのお問い合わせの未読の返信通知（`notifications`）も既読にする |
| 一覧の表示 | テーブルではなくカードのリスト（管理画面の一覧と揃えた）。§3 の項目に加えて内容の冒頭1行を出す。0件のときは空状態とお問い合わせフォームへの導線 |
| 送信（§4） | 2,000字まで。クローズ済み（対応済み）のスレッドには送信できない（API が 409）。運営側の表示名は「運営」 |
| 再オープン（§5） | ステータスを「未対応」に戻す。管理者への通知（メール・`admin_notifications`）は未実装のため、管理画面ダッシュボードの「未対応」件数で拾う |
| 導線（§2） | お問い合わせ送信完了画面（ログイン済みのみ）と設定ページ第9章に「お問い合わせ履歴」へのリンクを置いた。返信通知のクリックで該当スレッドへ遷移する |

## 2. アクセス条件・導線

| 項目 | 内容 |
|------|------|
| URL | `/contact/history` |
| アクセス条件 | ログイン済みユーザーのみ |

### 導線

| 導線元 | 内容 |
|--------|------|
| お問い合わせ送信完了画面 | 送信完了後に履歴ページへのリンクを表示 |
| 設定ページ（`/settings`） | 履歴確認用のリンクを設置（検討中） |
| 通知 | 管理者からの返信通知から直接該当スレッドへ遷移 |

## 3. 履歴一覧画面

ログイン済みユーザー自身のお問い合わせ一覧を表示する。

### 表示項目

| 列 | 内容 |
|----|------|
| 受付日時 | お問い合わせが送信された日時 |
| 種別 | お問い合わせ種別 |
| ステータス | 未対応・対応中・保留中・対応済みのバッジ表示 |
| 未読インジケーター | 管理者（オーナー・運営者）からの未読メッセージがある場合に表示 |

- 行をクリックするとスレッド詳細画面へ遷移する。
- デフォルトのソート順は受付日時の降順（新しい順）。

## 4. スレッド詳細画面

### 画面構成

```
┌─────────────────────────────────────────────────┐
│ ヘッダー                                         │
├─────────────────────────────────────────────────┤
│                                                 │
│ ← お問い合わせ一覧へ戻る                          │
│                                                 │
│ 不具合・バグ報告                   [ 未対応 ]     │
│ 受付日時: 2026-03-08 14:32                       │
│                                                 │
│ ── お問い合わせ内容 ──────────────────────────── │
│ 動画プレーヤーで○○をすると画面が固まります。      │
│                                                 │
│ 関連URL                                         │
│ https://puremite.net/player/xxxxx                │
│                                                 │
│ ── やり取り ──────────────────────────────────── │
│                                                 │
│  あなた  2026-03-08 14:32                        │
│  動画プレーヤーで○○をすると…                    │
│                                                 │
│            運営  2026-03-08 15:00               │
│            ご報告ありがとうございます。           │
│                                                 │
│ [ メッセージを入力                  ]            │
│                              [ 送信する ]        │
│                                                 │
│ ※ スレッドがクローズされている場合は入力不可       │
│ [ 再オープンする ]                               │
│                                                 │
└─────────────────────────────────────────────────┘
```

### スレッドの状態による表示切り替え

| 状態 | 入力エリア | 送信ボタン | 再オープンボタン |
|------|:---:|:---:|:---:|
| オープン中 | 表示 | 表示 | 非表示 |
| クローズ済み | 非表示 | 非表示 | 表示 |

## 5. 再オープン機能

スレッドが管理者によってクローズされた後、ユーザーが追加で連絡が必要な場合に再開できる機能。

### 再オープンフロー

```
「再オープンする」ボタンをクリック
    ↓
スレッドを再オープン
ステータスを「未対応」に自動変更
入力エリアおよび送信ボタンを再表示
```

- 再オープンが行われると、管理者側へ通知が送信される。
