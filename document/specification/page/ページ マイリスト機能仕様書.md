# ページ マイリスト機能仕様書

**バージョン**: v1.10
**作成日**: 2026年3月5日
**更新日**: 2026-10-07
**関連ドキュメント**:
- /document/specification/common/共通 uiコンポーネント フロント 仕様書.md
マイリストは、ログイン済みユーザーが自分の「追いかけている再生リスト」を一元管理するための機能である。複数の実況シリーズの視聴ステータスや視聴進捗を一覧で確認でき、効率的な「並走視聴」を実現する。
また、マイリストに登録している再生リストに新着動画が追加された際にユーザーへ通知を行う機能も提供する（通知アルゴリズムはYouTube定期取得バッチと連動）。

なお、マイリストへの登録データは、信頼度スコアリングシステムのジャンル専門性（G）の算出にも使用される。詳細は「信頼度スコアリングシステム仕様書」を参照すること。

### 1.2 アクセス条件

| 条件 | 内容 |
|------|------|
| ログイン状態 | ✅ マイリストページにアクセス可能 |
| 未ログイン状態 | ❌ アクセス不可（ログインページへリダイレクト） |

### 1.3 マイリスト登録のトリガー

再生リスト詳細ページに設置された視聴ステータス記録UI（「この再生リストに対して視聴ステータスを記録する」）で、いずれかの視聴ステータスを選択することで登録する（詳細は「ページ 再生リスト レビュー投稿機能 仕様書」の「視聴ステータス記録UI」節を参照）。基本情報セクションには重複する登録UIを置かない。

| ステータス | アイコン | 説明 |
|-----------|---------|------|
| 見たい（Plan to Watch） | 📋 | これから視聴する予定 |
| 視聴中（Watching） | ▶️ | 現在視聴中 |
| 完走（Completed） | ✅ | 最終話まで視聴済み |
| 一時中断（On Hold） | ⏸️ | 一旦中断中 |
| 断念（Dropped） | ❌ | 途中で視聴をやめた |

> **設計思想**: 「とりあえず登録」する場合は「見たい」、「続きから見る」場合は「視聴中」を選ぶことが多いと想定されるため、ユーザー自身が意図を持って選択できる設計にする。

**視聴ステータスの変更・解除**

- マイリストページ・再生リスト詳細ページのどちらからも、視聴ステータスの変更が可能（同じ `mylist.watchStatus` を共有する）
- 再生リスト詳細ページで選択済みの視聴ステータスを再クリックすると、選択が解除され、マイリストからも削除される
- 星評価またはレビューコメントのみを投稿した場合（視聴ステータス未選択）も、既定値「見たい」でマイリストに登録される

## 2. マイリストページ

### 2.1 ページ構成


### 2.2 空状態の表示

マイリストに登録されている再生リストが0件の場合（初回訪問時など）は以下を表示する。表示形式の詳細は「共通 uiコンポーネント フロント 仕様書」第8章（空状態）に準ずる。

| 要素 | 内容 |
|------|------|
| アイコン | お気に入り (`favorite`) アイコン |
| メッセージ | 「マイリストは空です」 |
| サブメッセージ | 「気になる動画をマイリストに追加して、自分だけのリストを作りましょう」 |
| アクションボタン | 「動画を探す」ボタン → `/playlists` へ遷移 |

### 2.3 読み込み失敗の表示

一覧の取得はTOPページのマイリストセクションと同じく、1回あたり15秒でタイムアウトして1回だけ自動で再取得し、画面に戻ったときにも読み込み中のまま止まっていれば再取得する（ページ top 仕様書 §5.7）。最終的に取得できなかった場合は、空状態（§2.2）ではなく以下を表示する。

| 要素 | 内容 |
|------|------|
| アイコン | 注意アイコン |
| メッセージ | 「マイリストを読み込めませんでした」 |
| サブメッセージ | 「通信状況をご確認のうえ、再読み込みしてください」 |
| アクションボタン | 「再読み込み」ボタン（secondary） → ページを再読み込み |

## 3. フィルタリング仕様

### 3.1 フィルタUIレイアウト

使用頻度に応じてタブの優先度を設計する。

```
[すべて] [視聴中] [見たい] [完走] [その他 ▼]
                                   └ 一時中断
                                   └ 断念
```

| タブ | 表示条件 | 優先度 |
|------|---------|--------|
| すべて | 常に表示（全ステータス） | 最高（デフォルト選択） |
| 視聴中 | 常に表示 | 高 |
| 見たい | 常に表示 | 高 |
| 完走 | 常に表示 | 中 |
| その他 ▼ | ドロップダウン（一時中断・断念） | 低 |

**「その他」ドロップダウンの挙動**

- クリックでドロップダウンを開き、「一時中断」「断念」を選択できる
- 「一時中断」または「断念」が選択されている場合、タブ部分に「その他：一時中断」のように選択中のステータスを表示する

**スマホ幅での表示**

- タブ列が画面幅に収まらない場合も折り返さず、1行のまま横スクロールにする（共通 デザイントークン仕様書 §15.3）
- 続きがある側の端をフェードさせて、スクロールできることを示す
- 選択中のタブ（「その他：一時中断」を含む）は表示範囲まで自動で横スクロールする

### 3.2 各タブの件数表示

各タブには件数バッジを表示し、ユーザーが全体像を把握しやすくする。

```
[すべて 24] [視聴中 12] [見たい 5] [完走 6] [その他 ▼ 1]
```

| ソート | 説明 | デフォルト |
|--------|------|-----------|
| 最後に再生した動画（新しい順） | 直近に動画を開いた再生リストが上に表示される | ✅ デフォルト |
| 再生リスト名（昇順） | 再生リストのタイトルのあいうえお順 | — |

> **設計思想**: 「続きを見たい」というユーザーの自然な動線に沿って、直近に触れた再生リストを上位に出すことで、再生への摩擦を最小化する。

## 5. カード仕様

### 5.1 カードのデザイン方針

一枚のカードの中に「再生リストについての情報」と「最後に再生した動画」を親子関係がわかるように表示する。

```
┌────────────────────────────────────────────────────────┐
│ ┌──────────┐  「◯◯実況」                               │
│ │ 再生リスト│  配信者サムネイル  配信者名               │
│ │サムネイル │                                          │
│ │          │  [ステータスバッジ] ▶️ 視聴中              │
│ └──────────┘                                          │
│ ─────────────────────────────────────────────────      │
│  最後に再生した動画                                     │
│  ┌────────────┐  動画タイトル（Part 8「〇〇編」）       │
│  │ 動画       │  進捗バー                              │
│  │ サムネイル │                                        │
│  └────────────┘                                       │
└────────────────────────────────────────────────────────┘
```

### 5.2 再生リスト情報エリア（親）

| 表示要素 | 詳細 |
|---------|------|
| 再生リストのサムネイル | YouTube再生リストのサムネイル画像 |
| 再生リストのタイトル | 最大1〜2行、超過時は省略記号（…） |
| 配信者のサムネイル | 小さな円形のチャンネルアイコン |
| 配信者名 | チャンネル名 |
| 視聴ステータスバッジ | 現在のステータスをアイコン＋テキストで表示（例: ▶️ 視聴中） |

### 5.3 最後に再生した動画エリア（子）

親エリアと視覚的に区切り（境界線または背景色の差異）を設け、「この再生リストの中の動画」であることを明示する。

| 表示要素 | 詳細 |
|---------|------|
| 動画サムネイル | 最後に開いた動画のサムネイル画像。右下に動画の再生時間（全体の長さ）をラベルで重ねる（表記は動画リストと同じ `h:mm:ss`／`m:ss`。尺が取れない動画は出さない） |
| 進捗バー | サムネイル下部に視聴進捗%をバー形式で表示（詳細仕様は「プレミテ動画プレーヤー仕様書」の「右カラム＞動画リスト＞進捗バー」に準ずる） |
| 動画タイトル | 最後に開いた動画のタイトル。長い場合も省略せず折り返して全文表示する |
| 残り時間 | タイトル下に「残り N 分」（1時間以上は「残り N 時間 M 分」）。尺が取れない動画は出さない |
| 「続きから再生」ボタン | 動画プレーヤーページへ遷移し、最後に開いた話数・再生位置から**自動で再生を開始する**（下記） |

**「続きから再生」ボタンの動作**

- 遷移先の動画プレーヤーページで、ユーザーが再生ボタンを押さなくても再生を開始する（開始までの間は待機表示の再生ボタンがスピナーに変わる。動画プレーヤー仕様書「自動再生」参照）。ユーザーが同じ意味のボタンを2回押さずに済むようにするため
- ブラウザの自動再生制限で再生が始まらない場合は、通常の待機表示のままとし、ユーザーが再生ボタンを押して開始する（ミュートでの自動再生はしない）
- **自動再生できないことが分かっている環境**（iOS / iPadOS の全ブラウザ、macOS の Safari。WebKit 系は音声ありの再生をユーザー操作の直後にしか許可せず、ページ遷移を挟むと必ずブロックされる。2026-09-24 iOS Safari 実機で確認）では、ボタンのラベルを「**再生ページへ**」（右向き矢印アイコン）に変え、自動再生を試みない通常の遷移にする。遷移先で再生されないのに「続きから再生」と表示すると、ラベルと挙動が食い違うため
  - 判定は User-Agent による推定。誤判定で自動再生に失敗した場合も、上記のとおり待機表示に戻る
- 自動再生するのはこのボタンのみ。サムネイル・タイトルのクリック（§5.6）や TOP ページのマイリストカードからの遷移では自動再生しない（内容の確認など閲覧目的の場合もあるため）
- 実装: `/playlists/[id]?autoplay=1` へ遷移する。動画プレーヤーページはクエリを読み取った後すぐに除去する（リロード・「戻る」で開き直したときに再び自動再生しないため）

### 5.4 最後の動画を視聴済みの場合の表示

再生リストの最終動画を視聴済みの場合、子エリア（最後に再生した動画）は非表示になる。

**新着動画がある場合の通知**

YouTubeの再生リストに新しい動画が追加されている場合、子エリアの代わりに新着通知を表示する。

```
┌────────────────────────────────────────────────────────┐
│ ┌──────────┐  「◯◯実況」                               │
│ │ 再生リスト│  配信者サムネイル  配信者名               │
│ │サムネイル │                                          │
│ └──────────┘  ✅ 完走                                  │
│ ─────────────────────────────────────────────────      │
│  🔔 NEW  新着動画があります                             │
└────────────────────────────────────────────────────────┘
```

| 表示要素 | 詳細 |
|---------|------|
| アイコン | 🔔（ベルアイコン） |
| テキスト | 「NEW」の文字 + 「新着動画があります」 |
| 話数 | **非表示**（話数は表示しない） |

**新着通知の表示制御**

新着通知の表示はユーザーがトグルでON/OFFを制御できる。

| 設定 | 動作 |
|------|------|
| ON（デフォルト） | 新着動画がある場合に🔔 NEW を表示する |
| OFF | 新着通知を非表示にする（完走後は子エリアが空のまま） |

設定の保存先：
- ログイン済みユーザー：Firestoreのユーザードキュメントに保存
- 未ログインユーザー：（マイリストページはログイン必須のため対象外）

### 5.5 逆順トグル

再生リストによっては動画の並びが逆順（新しい動画がPart 1に近い位置に登録されている）の場合があるため、各カードに逆順トグルを設置する。

| 設定 | 動作 |
|------|------|
| OFF（デフォルト） | 再生リスト本来の順序で表示・再生 |
| ON | 再生リストの順序を反転して表示・再生 |

**保存範囲**: ユーザーごと、かつ再生リスト単位で保存（動画プレーヤーページの逆順トグルと設定を共有する）

**ボタン文言**: ON/OFFの状態がラベル文言でも判別できるよう、ONの間はボタンラベルを「逆順再生中」（コンパクト表示時は「逆順中」）に変更する（OFFは「逆順で再生」／コンパクト表示時「逆順」）。

### 5.6 カードのクリック動作

カードをクリックすると、その再生リストのページ（動画プレーヤーページ）に遷移する。

- 遷移先では「最後に開いた話数」から再生を開始できる（動画プレーヤー仕様書に準ずる）。自動再生はしない（自動再生するのは子エリアの「続きから再生」ボタンのみ。§5.3）

---

### 5.7 ステータスの自動更新

視聴進捗に応じた自動ステータス変更は**行わない**。ステータスはユーザーが手動で変更する。

補足: 再生リスト詳細ページで表示順の最後の動画を見終えたときは「完走」にするかを確認するダイアログを出す（動画プレーヤー仕様書「最終話の再生終了時」章）。変更されるのはユーザーが「完走にする」を押した場合のみで、自動では変更しない。

> **設計思想**: 自動変更はユーザーの意図と乖離する場合があるため、シンプルに手動管理とする。

### 5.8 ステータス変更のUI

各カード上に「ステータス変更」のUIを設ける（例: バッジをクリックするとステータス選択ドロップダウンが開く）。

対象はマイリストページ（`/mylist`）のカード。TOPページのマイリストカードはステータス変更の操作を持たない一覧専用の簡易カードで、ステータスは表示のみとする（ページ top 仕様書 §5.4）。

### 5.9 マイリストからの削除

カードの「削除」ボタンを押すと、すぐには削除せず確認ダイアログを表示する（誤タップ防止）。ダイアログでは、何が解除されるかと、視聴の進捗・レビューは残ることを短い文章で伝える（項目の列挙はせず、ユーザーが気にする点に絞る）。

| 要素 | 内容 |
|------|------|
| タイトル | 「マイリストから削除しますか？」 |
| 説明 | 「『{再生リスト名}』の視聴ステータスと新着動画のお知らせが解除されます。視聴履歴やレビューは残るので、もう一度追加すれば続きから見られます。」 |
| ボタン | 「キャンセル」（閉じるのみ）／「削除する」（削除を実行し、完了後にトースト「マイリストから削除しました」） |

- 実際の削除内容: 視聴ステータス・逆順再生の設定・この再生リストの今後の新着動画のお知らせが消える（作成済みの通知は通知一覧に残る）。視聴履歴・再生位置・星評価・レビューコメントは残る。逆順再生の設定は影響が小さいためダイアログには明記しない
- Esc・オーバーレイクリック・×ボタンでも閉じる（キャンセル扱い）。削除の通信中は閉じない
- 削除に失敗した場合はエラートースト「通信エラーが発生しました。時間をおいて再試行してください」を表示してダイアログを閉じる（カードは残る）
- 削除時は、レビュー側に複製している視聴ステータス（`reviews.watchStatus`）もあわせて解除する。星評価・コメントがあるレビューはそのまま残し、ステータスだけを外す。どちらも無い（ステータスのみの）レビューはレビューごと削除する。再生リスト詳細ページで選択済みのステータスを再クリックして解除した場合（§1.3）と同じ結果になる（星評価・コメントが残る場合は、完走による視聴深度D=1の固定が外れるため、信頼度スコアと再生リストスコアを再計算する）

## 6. TOPページとの連携

TOPページには、マイリストの情報をもとにした以下のセクションを設ける。詳細な仕様は別途定義する。

| セクション | 内容 |
|-----------|------|
| 視聴中の動画 | マイリストの「視聴中」ステータスの再生リストのうち、最後に再生した動画を表示 |
