## 1. 概要

プレミテは、実況者の同意を取らずに YouTube の公開情報（チャンネル・再生リスト・動画）を掲載する（リブランディング検討 項目8、2026-11-01 決定）。そのかわり、実況者・事務所の方に向けて、プレミテが何をしているか、掲載を外す方法、掲載を申請する方法を分かりやすく丁寧に伝えるページを用意する。

- 掲載を外してほしいという申し出には、**すぐ**（チャンネル単位で）掲載を止める（コンテンツ収集機能仕様書 §10.6）。
- 「YouTube・掲載チャンネルと提携していません」の明記はしない（項目9 決定）。ただし、YouTube が推奨・承認しているかのように見せる表現も使わない。
- 「認定」という言葉は使わない。

## 4. ページ構成

文言はすべて仮。丁寧語で、短い段落に分ける。

| セクション | 内容（仮文言の要旨） |
|---|---|
| ① プレミテについて | 「プレミテは、ゲーム実況のシリーズ（再生リスト）を、最初から順に・続きから見られるようにし、視聴者が記録とレビューを残せるサービスです。」 |
| ② 掲載のしかた | 「YouTube で公開されているチャンネル・再生リストの情報を、YouTube の公式の仕組み（YouTube Data API と埋め込みプレーヤー）で表示しています。動画は YouTube のプレーヤーで再生されるため、再生は YouTube 上のチャンネルの視聴として数えられます。」「掲載するチャンネルは運営が選んでいます。実況者ご本人・公式のチャンネルだけを掲載し、切り抜き・転載のチャンネルは掲載しません。」 |
| ③ 掲載を外してほしいとき | 「掲載を望まれない場合は、お問い合わせからお知らせください。確認でき次第、チャンネル単位ですぐに掲載を止めます。」ボタン「掲載についてお問い合わせ」→ `/contact?type=channel_listing`（種別「チャンネルの掲載について」を選んだ状態。ページ お問い合わせフォーム仕様書 §4）。案内: 「チャンネル名またはチャンネルのURLを書き添えてください。」 |
| ④ 掲載を申請したいとき | 「まだ掲載していないご自身（または所属タレント）のチャンネルの掲載を申請できます。」ボタン「掲載を申請する」→ `/channels/apply`（ログインが必要）。「アカウントを作らずに申請したい場合は、お問い合わせからでも受け付けます。」 |
| ⑤ よくある質問 | 「掲載に費用はかかりますか」→かかりません。「レビューを消してもらえますか」→不適切なレビューは通報・お問い合わせから確認します。「掲載されている情報が古い」→毎日 YouTube から取り直しています（反映まで1日ほどかかります）。 |

- お問い合わせで掲載停止の申し出を受けた運営は、認定チャンネル画面の「掲載を止める」（収集候補レビューUI仕様書 §9.3）を実行し、お問い合わせに返信する。
