# 自動掲載の確認 — ゲーム画像・チャンネルアイコン・付いているゲームの詳細

PR #28（`12bbe91`、2026-11-12）と PR #30（`0bcd25b`、2026-11-14）。仕様は 収集候補レビューUI v3.5・v3.6（§8.2・§8.3）、コンテンツ収集 v4.4（§10.11）。

## PR #28: 画像とアイコン

- 「自動掲載の確認」でゲームのパッケージ画像が出ていなかったのは、段階4で旧「収集候補」画面を置き換えたときの抜け。ゲーム名の左に画像（幅40px、`packageImageSrc(..., 'card')`）
- チャンネル見出しにアイコンと、`/channels/{youtubeChannelId}` を別タブで開くリンク（`channels` ドキュメントがあるときだけ）。`ChannelAvatar` を `components/admin/collection/ChannelAvatar.tsx` に切り出した
- **アイコンが空だった原因**: 段階3の移行スクリプトが掲載チャンネルを `channelIconUrl: null` で作り、巡回がそれを新しい再生リストにコピーしていた（stg で 2,911件中 2,412件が空）。
  `lib/channel-sweep.ts` で、空なら `channels.iconUrl` → YouTube `channels.list`（1ユニット）の順で補い、空の再生リスト・チャンネルページも埋める。本番もデータ移行なしで、次の毎日の巡回で直る
- 初回だけ書き込みが多く、手動の「巡回を実行」は画面に「失敗」と出ても処理は成功していた

## PR #30: 付いているゲームの詳細

- 「ゲームは決めなくても掲載できます。」を各カードから一覧の上の1か所へ
- ゲームの画像・名前を押すと「付いているゲーム」モーダル（`components/admin/collection/LinkedGameModal.tsx`、開くたびに `games/{gameId}` を読む）。ゲーム名・別名・機種・ジャンル・掲載中の件数、楽天ブックスで選ばれている商品のページ（`games.rakutenUrl`、アフィリエイトなし）、ゲームタイトル詳細（編集）へのリンク
- ユーザーは「楽天市場」と言うことがあるが、実際に使っているのは楽天ブックス

## E2E のハマりどころ

`[E2E]` を含む名前を `new RegExp` に入れると `[...]` が文字クラスになって当たらない。ボタン名などは文字列で指定する。
