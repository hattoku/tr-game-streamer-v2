# フェーズ2.5 ステップ3 — 再生リスト詳細ページのデザイン適用

[[2026-09-11-phase2.5-design-plan]] のステップ3。フェーズ2でノースタイルだった
`app/(main)/playlists/[playlistId]/page.tsx` を、再生リスト詳細 仕様書・動画プレーヤー 仕様書に
沿って部品化し、[[2026-09-11-design-foundation]] のトークンで組み直した。

## 分割した部品（`components/playlists/`）

| ファイル | 内容 | 根拠 |
|---|---|---|
| PlaylistInfoCard.tsx | 基本情報カード: タイトル1行省略／スコア（null は「評価なし」）・マイリスト数・レビュー数／タグ（現状は空）／YouTube参照リンク／マイリスト追加ボタン枠 | 再生リスト詳細 仕様書「基本情報セクション」、スコアリング仕様書 |
| VideoList.tsx | 動画リスト: 話数番号・サムネ＋進捗バー・タイトル2行・尺、再生中ハイライト（`bg-bg-list-active`）＋▶、「全XX話」、逆順チェック。リスト内スクロール（PC は `calc(100dvh-220px)`）で現在の動画を上端へ自動スクロール | 動画プレーヤー 仕様書「動画リスト」「進捗バー」「初期スクロール位置」 |
| ChannelCard.tsx | 配信者カード: 48px 円形アイコン・名前・「他の再生リストを見る →」→ `/channels/[channelId]` | 再生リスト詳細 仕様書「配信者情報セクション」 |

## ページ本体

- PC: `grid-cols-[62fr_38fr]`（左: ヒーロー、右: 基本情報→動画リスト→配信者）。モバイル: ヒーロー→基本情報→
  動画リスト→配信者 の縦積み（基本情報カードは PC 用と モバイル用の2箇所に描画し `md:hidden` / `hidden md:block`
  で出し分け）。
- ヒーロー: 開始前はサムネイル＋中央の▶オーバーレイ（クリックでも開始）、下に「再生する／続きから再生する」
  プライマリボタン、続きからのときは進捗バー＋「残り○分」。開始後はコントローラ（前へ／再生・一時停止／次へ／
  シアター／連続再生チェック）。前へ・次へは動画が無ければ非表示（仕様「コントローラボタン表示ルール」）。
- **シアターモード**: ヘッダーを `LayoutContext` 経由で 30px・黒背景に、ヒーローを黒背景でコンテンツ幅いっぱい
  （`-mx-4 -mt-6` で PageContainer の余白まで広げる）、その下に 基本情報 | 動画リスト・配信者 の2カラム。
  ページを離れると `setCompactHeader(false)` でリセット（状態は保持しない仕様）。
- 存在しない ID は `notFound()`（クライアントコンポーネントから throw）→ 共通 404 ページ。
- 読み込み中はページ固有のスケルトン（`DetailSkeleton`）。

## ハマりどころ・実装上の判断

- **YouTube iframe を破棄しないため、シアターモード切替で DOM 構造を変えない**。当初モード別に別ツリーを返す
  実装にしていたが、それだと親が変わって React が再マウントし、`YT.Player` が差し替えた iframe が消えて
  `playerRef` が死ぬ。左右カラムの div は固定し、`md:col-span-2` や右カラムを `md:grid` にするクラス切替だけで
  レイアウトを変えるようにした。
- `#yt-player-target` の div は常に描画し、開始前はサムネイルのボタンを上に重ねる。`YT.Player` には
  `width: '100%', height: '100%'` を渡し、`aspect-video` の箱いっぱいに iframe を広げる
  （指定しないと 640×390 固定になる）。
- 連続再生の判定は `continuousPlayRef` で参照する（`onStateChange` のクロージャが古い state を掴む問題を回避）。
- 逆順トグルは動画リストのヘッダーに置いた（仕様はマイリストカードと共有設定であることのみ規定）。
  マイリスト未登録時は「保存されません」の注記。
- 星の半分表示（半星）はレビュー機能（フェーズ3）で SVG 対応。現状 score は常に null で「評価なし」。
- `playlists.mylistCount` はクライアントから更新できない（ルール）ため、追加しても数値は増えない。
  サーバー側集計はフェーズ3。
- マイリストページの暫定「追加フォーム」は本来の設置場所（このページ）に移ったので、ステップ4で削除する。

## 動作確認

- `npx tsc --noEmit` / `npm run build` 成功。
- 本番 Firestore に公開再生リストが 0 件のため、実ブラウザでの再生確認には管理者アカウントで
  `/playlists/new` から1件登録する必要がある（テストモード用会員は role user のため登録不可）。
  存在しない ID の 404 は curl で確認。
