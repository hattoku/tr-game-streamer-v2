# リブランディング段階6 — チャンネル申請・提案の分岐・実況者向けページ

PR #24（`ae510b9`、2026-11-08）。仕様は ページ チャンネルを申請する v1.2、審査ワークフロー v12.2（§15）、再生リストを追加する v5.2、実況者・事務所の方へ v1.1、データモデル v2.6。

## 変更

- `/channels/apply`: 本人・事務所の申請と視聴者の推薦。URL・@ハンドル・UC…・再生リスト URL から YouTube で確認（`lib/channel-application-server.ts`、`POST /api/channels/apply`）
  - 掲載中／掲載停止／申請済みは受け付けない。**同じチャンネルに審査中の申請があれば2件目以降は受け付けない**（ユーザー決定）。推薦の数は数えない
  - 1人1日5件まで
- 審査: 管理画面の「提案」に「チャンネル申請」（`workflows` の `channel_application`）。承認で掲載チャンネル（`publishMode: 'confirm'`）にし、応答後に巡回を1回実行。定型の見送り理由・申請者への通知・提案履歴
- 提案の分岐: 再生リスト提案は掲載中のチャンネルだけ。未掲載は「このチャンネルを申請する」へ、掲載停止は受け付けない（提案時・承認時の両方で確認）
- `/creators`（実況者・事務所の方へ）、フッター・メニューの導線、お問い合わせの種別「チャンネルの掲載について」（`?type=channel_listing`）、再生リストを追加する画面のフォーム下の案内カード

## 未実装（再生リスト提案の作り直しに回す）

再生リストを追加する §10.2〜10.4（未掲載チャンネルの既存再生リストの提案、ゲーム任意、管理者登録でチャンネルも同時に掲載）。「初めての方へ」→実況者向けの導線は `/about` の本文整備のときに。
