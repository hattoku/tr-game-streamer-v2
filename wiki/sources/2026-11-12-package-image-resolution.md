# スマホのゲーム詳細 — パッケージ画像の画質とレイアウト

PR #27（`0ae9bac`、2026-11-12）。仕様は ページ ゲームタイトル 詳細 v2.9（§3.1・§3.2・§6.1・§6.2）、ゲームタイトル 探す v1.7。

## 原因

- 画質: `games.packageImageUrl` は楽天ブックス API の `largeImageUrl` そのままで、末尾が `?_ex=200x200`（縦長で約123×200px）。スマホの全幅（3倍密度で900px前後）だと約7倍に引き伸ばされていた → [[楽天画像URLのサイズ指定]]
- レイアウト: スマホでも画像を全幅で上に出していた（仕様の想定は小さく）

## 変更

- `lib/package-image.ts` の `packageImageSrc(url, 'detail' | 'card')` で、表示時に `_ex` を差し替える（詳細 `600x600`、一覧カード・関連ゲーム `400x400`、楽天以外の URL はそのまま）
- **保存データは書き換えない**（アフィリエイトリンクと同じ「表示時に付ける」方式）。移行も backfill の再実行も要らず、デプロイだけで直る
- スマホのレイアウト（ユーザー選択）: 幅112pxの画像を左上、右にジャンル・テーマ・件数・楽天ボタン、その下にタグ・説明文・編集ボタン。PC は従来どおり。要素を二重に描かないよう CSS グリッドで配置を切り替えた（[[CSSグリッドのmin-width対策]] も参照）
- E2E: `e2e/package-image.spec.ts`
