# 7-5追加 — 推定なしの収集候補もまとめて承認し、候補を動画10本以上に絞る

PR #10（`5da5a5e`、2026-10-28 に PR #8 と一緒に main へ）。仕様は 収集候補レビューUI v2.1・コンテンツ収集機能 v3.1。

## 経緯

stg で有名チャンネル3つを探索したら候補441件がすべて「ゲーム推定なし」だった（stg のゲームタイトルが21件しかないため）。推定なしは1件ずつ承認する作りで、承認しきれなかった。

## 変更

- 推定なしの候補に「新規」の印とゲーム名の入力欄（初期値は `gameQuery`）。全選択でまとめて承認できる
- 承認 API が `newGameTitle` を受け付ける（`lib/collection-game.ts`）: 既存ゲームのタイトル・別名と正規化して一致すれば使う → 無ければ新規登録（楽天ブックスに一致があれば画像・URL・機種・ジャンル・テーマも）→ 再生リストが1件も付かなかった新規ゲームは消す
- 承認は20件ずつ、新しいゲーム名を含む候補は5件ずつ送る（Hosting の60秒上限のため）。楽天 API は10秒で打ち切る
- 探索のハードフィルタの最小動画数を10本に、除外語に「単発」

## E2E で確かめていないこと

- 楽天で一致したときに画像などが入る経路（stg の実データ頼み）
- 同じリクエスト内の同名の新規ゲームが1件にまとまること
