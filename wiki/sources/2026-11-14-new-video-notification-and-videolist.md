# 再生リスト新着の通知と動画リストの投稿日・NEW・再生時間・見出し

仕様は ユーザー通知機能 v1.4〜v1.5、データモデル v2.9、FCM プッシュ通知基盤、設定、動画プレーヤー v1.19〜v1.21。#32 以降は Notion「🎮 プレミテ タスク」の子タスクから。

## PR #31: 新着通知と投稿日

- 背景: ベルの新着通知から開いても、どの動画が新しいか分からない。同名の再生リスト（例「ダビスタ 2」）が別の配信者にもあり、通知の文だけでは区別できない
- 通知に配信者のアイコン・名前と、新しい動画のタイトル（先頭1本＋「ほかN本」）。**動画のサムネイルはネタバレになるので出さない**（ユーザー決定）
  - 通知作成時に `channelName`・`channelIconUrl`・`newVideoTitles`（先頭5本）・`newVideoCount` を保存（`lib/new-videos-refresh.ts`、表示は `lib/notification-format.ts`）。古い通知は再生リストから配信者名・アイコンだけ補う
  - 通知を押したときに選ぶ動画は従来どおり「続きから」
  - 種別名は「シリーズ新着」から「**再生リスト新着**」へ（ユーザー指摘）。スマホで種別ラベルを改行させない
- 動画リストに投稿日と、投稿または再生リストへの追加から7日以内の小さい「NEW」（`NewBadge size="sm"`）
- **投稿日の修正**: `playlistItems` の `snippet.publishedAt` は再生リストに追加された日時だった。`contentDetails.videoPublishedAt` を `videos.publishedAt` に、追加日時を `videos.addedToPlaylistAt` に保存。ユニット数は同じ。既存データは次の取り直しで直る → [[YouTube Data APIのハマりどころ]]

## PR #32: 投稿日を常に年つきに

今年の動画は「11/12」と年を省いていたが、昔の動画があとから足されることがあるため常に「2026/11/12」。尺・投稿日・NEW の行は狭い幅では項目単位で折り返し、日付の途中で改行しない（320px・390px で確認）。

## PR #33: 見出しを「再生リストの登録動画」に

画面の見出し「動画リスト 150話」を「再生リストの登録動画 150話」に。「再生リスト」と「動画リスト」が並ぶと別物に見えるため。**仕様書・コード上の呼び名は「動画リスト」のまま**。設定画面の「先の話のサムネイルを隠す」の説明文も合わせた。

## PR #34: 再生時間をサムネイルの右下に

タイトル下で投稿日と並ぶと「その時刻に投稿された」と読めるため、サムネイル右下の半透明ラベル（`CountLabel`、マイリストの「最後に再生」と同じ見た目）へ。尺が取れない動画はラベルを出さない（以前は `--:--`）。先の話を隠している行でも黒い枠の右下に出す。

## E2E のハマりどころ
