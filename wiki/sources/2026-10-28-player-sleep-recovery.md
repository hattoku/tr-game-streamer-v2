# 動画プレーヤー — スリープ復帰で再生位置が消える問題と、作り直し後の表示

PR #12（`d4bcb35`、2026-10-28）と PR #22（`2c0c83a`、2026-11-04）。仕様は 動画プレーヤー仕様書 v1.17・v1.18（「再生時間の記録タイミング」「プレーヤーの不調からの復帰」）。

## PR #12: 再生位置が 0 で上書きされる

- 症状: Mac Safari で一時停止したままスリープ→半日後に復帰すると YouTube 埋め込みが「エラーコード 152-18」。再読み込みすると再生位置が最初に戻っていた
- 原因: 5秒ごとの保存タイマーが一時停止中も止まらず、復帰直後の不調なプレーヤーが返した 0 秒で `watch_progress`（と `watch_history` の%）を上書きしていた
- 保存: 定期保存は再生中だけ。一時停止・タブ非表示・`pagehide`・ページ内遷移・前へ／次へ／リスト選択の直前・エラーでも保存する。
  プレーヤーから読むのは「再生中・一時停止中・バッファ中」かつ動画の長さが取れて対象の動画を読み込んでいるときだけ。再生中でなければ「最後に正常に読み取れた位置」を保存する
- 端末内の控え: LocalStorage `puremite:watch-progress:{uid}:{playlistId}`。読み込み時に Firestore より新しければ控えを使い、Firestore にも書き戻す
- 復帰: 30秒タイマーで時計が10分以上飛んだ、または非表示が10分以上続いたら、再生中でなければプレーヤーを作り直す（保存位置で cue、自動再生しない）。
  `onError` でも位置を保存して作り直し、60秒以内に再びエラーなら「ページを再読み込み」を案内
- 作り直せるよう、マウント先を id 指定から ref の子要素にした
- E2E: `e2e/player-progress.spec.ts`、`e2e/support/watch-progress.ts`（テスト用会員の進捗を退避・復元）。ヘッドレスでは YouTube の再生が始まらないため、再生を伴うテストは判定してスキップする

## PR #22: 作り直したあと進捗バーが出ない

- 症状: PC で一時停止→画面ロック→半日後に復帰すると、大きいプレーヤーに進捗バーが無く、どこまで見たか分からない
- 原因: 作り直した埋め込みは未再生（cue）表示でシークバーが出ない。プレミテ側の「続きから再生する」と前回位置の進捗バーは `playerStarted === false` のときしか出さない
- 対応: `rebuildPlayer()` で `playerStarted` を false に戻し、ページを開いたときと同じ再生開始前の表示に戻す。`onError` での作り直しも同じ
- 実機（Mac Safari）での確認はユーザーが後日行う

## 原則

進捗まわりを変えるときは「**不調なプレーヤーの値で上書きしない**」を守る。
