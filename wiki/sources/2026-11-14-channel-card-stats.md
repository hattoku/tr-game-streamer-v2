# 再生リスト詳細の配信者欄に件数を出す

PR #35（2026-11-14）。Notion「ユーザビリティ改善」の子タスク「配信者欄の情報拡充」。仕様は ページ 再生リスト詳細 v1.17（配信者情報セクション「件数」）。

## 変更

- `components/playlists/ChannelCard.tsx`: チャンネル名の下に「N 再生リスト・N 動画・N マイリスト」を出す（アイコンはチャンネル詳細の見出しと同じ）
- 数は一覧 API `/api/catalog/playlists?channelId=` の `total`・`totalVideoCount`・`totalMylistCount` をそのまま使う（[[2026-11-08-rebranding-stage7-server-search]] のサーバーの索引）。チャンネル詳細ページの見出しと同じ数え方（掲載中の再生リストだけ）になり、**YouTube API の消費は増えない**
- 読み込み中・失敗時は件数の行を出さない（「0」が一瞬出るのを避ける）。別のチャンネルの再生リストへ移ったとき前の数を出さないよう、取得結果にチャンネルIDを持たせて照合している
- E2E: `e2e/channel-card-stats.spec.ts`（掲載していない再生リストは数えない・合計・レビューを出さない・横スクロールなし）

## ユーザー決定

- レビュー数は初期は集まらないので出さない（Notion のタスク本文）

## メモ

- 開いている再生リスト自体が掲載していないもの（URL・マイリストから開ける）でも、件数は掲載中の分だけ。チャンネル詳細と揃えるため意図どおり
