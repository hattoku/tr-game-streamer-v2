# デザイントークン運用方針

`document/specification/common/共通 デザイントークン仕様書.md`（v2.0）のトークンを
コードでどう扱うかの取り決め（フェーズ2.5で確立 [[2026-09-11-design-foundation]]、
v2.0 で改訂 [[2026-09-12-design-direction-crimson]]）。

## 定義場所は `app/globals.css` の `@theme` 一箇所

- Tailwind v4 の `@theme` に CSS 変数として定義する。仕様書のトークン名に `--` を付ける
  だけの機械的な対応（`color-text-muted` → `--color-text-muted`）。
- 生成されるユーティリティ: `bg-bg-card` / `text-text-muted` / `border-border-card` /
  `shadow-card` / `inset-shadow-highlight` / `animate-fade-in` / `h-header` / `text-heading` など。
- **面のグラデーション**（仕様書 §6.1, §13, §16）は `@theme` に入れられないので `@utility` で定義する:
  `bg-gradient-card`（カード）/ `bg-gradient-elevated`（浮遊面）/ `bg-gradient-primary`（赤）/
  `bg-gradient-secondary`・`-hover` / `bg-header` / `bg-gradient-bottom-tabs` / `bg-thumb-overlay`。
  トグルON等で面の色を差し替えるときは `bg-none` で `background-image` を消してから `bg-bg-selected` を当てる。
- 仕様書に無い値を色として直書きしない。必要になったら**仕様書に追記してから**
  `@theme` に足す（`.agent/rules/development_flow.md` の「仕様書が主」）。
  例外は data URI 内の色。

## 仕様書の値をそのまま使うための小技

| 仕様書の指定 | 書き方 |
|---|---|
| 境界線 | v2.0 から **1px の半透明白**に統一。`border border-border-card`（カード）/ `border-border-control`（ボタン・入力）/ `border-t border-border-divider`（区切り）。`border-[0.5px]` は使わない（高DPI以外で消える） |
| 角丸 | カード・モーダル 12px、ボタン 8px、入力 7px、ドロップダウン 10px、チップ 20px → `rounded-[12px]` 等の任意値 |
| パディング 9px 22px | `px-[22px] py-[9px]` |
| フォントサイズ | `text-xs`(10) / `text-sm`(11) / `text-md`(12) / `text-base`(13) / `text-lg`(14) / `text-xl`(15) / `text-2xl`(16) / `text-heading`(18) / `text-score`(26)。**Tailwind 標準とは値が異なる** |
| 影 | `shadow-card` / `shadow-card-hover` / `shadow-elevated` / `shadow-control` / `shadow-primary`。ボタンの上端ハイライトは `inset-shadow-highlight`（プライマリは `-strong`）。外側の影と同時に指定できる |
| トランジション 120ms | `transition-colors duration-[120ms]`（浮き上がりは `transition-[transform,border-color,box-shadow]`） |
| 見出し | `SectionHeading`（18px bold）。カード内見出しは `CardTitle`（15px medium） |

## 刺し色の使い方（仕様書 §1.2、v2.0）

- 赤: ロゴ・プライマリボタン・進捗バー・未読ドット・再生中バッジ・サムネイル上の再生ボタン。
- 琥珀=★スコア、緑=視聴中、青=注目上昇中、楽天オレンジ=楽天ボタン、のみ。
- **2色目は足さない**。アクティブ表示（タブ下線・ナビ下線・選択中チップ・トグルON・フォーカス）は白系
  （`border-border-active` / `bg-bg-selected` / `text-text-primary`）で表現する。
- グロー（発光）は使わない。影は黒のみ、赤い影はプライマリ面にだけ。

## 奥行きの3段階（仕様書 §16）

| 段階 | 部品 | 書き方 |
|---|---|---|
| 0 フラット | 見出し・動画リスト・タブ列 | 背景に直接。区切りは `border-border-divider` / `border-border-tabs` |
| 1 カード | `Card`（`interactive` でホバー浮き上がり） | `bg-gradient-card border-border-card shadow-card` |
| 2 浮遊面 | `Modal` / `DropdownMenu` / `Toast` / ドロワー | `bg-gradient-elevated border-surface-border shadow-elevated` |

## ブレークポイント

Tailwind 標準の `md:`（768px）が共通 ページレイアウト 仕様書 §2 の PC/モバイル境界と
一致するため、独自のブレークポイントは定義しない。`md:` = PC、無印 = モバイル。

## 挙動はヘッドレスUI、見た目はトークン

- モーダル・ドロワー・ドロップダウン・タブ・トーストは Radix UI Primitives のラッパー
  （`components/ui/`）を通して使う。ページ側で Radix を直接 import しない。
- **セレクトはブラウザ標準の `<select>` を使わない**（OSのダーク配色と混ざり文字が読めなくなる。
  仕様書 §10）。`SelectMenu`（`components/ui/DropdownMenu.tsx`）を使う。
- 完成品UIライブラリ（HeroUI / Mantine 等）はフロントには入れない（ユーザー決定）。
