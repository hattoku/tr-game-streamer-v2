# デザイントークン運用方針

`document/specification/common/共通 デザイントークン仕様書.md` のトークンを
コードでどう扱うかの取り決め（フェーズ2.5で確立、[[2026-09-11-design-foundation]]）。

## 定義場所は `app/globals.css` の `@theme` 一箇所

- Tailwind v4 の `@theme` に CSS 変数として定義する。仕様書のトークン名に `--` を付ける
  だけの機械的な対応（`color-text-muted` → `--color-text-muted`）。
- 生成されるユーティリティ: `bg-bg-card` / `text-text-muted` / `border-border-strong` /
  `shadow-elevated` / `animate-fade-in` / `h-header` など。
- 仕様書に無い値を色として直書きしない。必要になったら**仕様書に追記してから**
  `@theme` に足す（`.agent/rules/development_flow.md` の「仕様書が主」）。
  例外は `decoration-[#555555]`（タグ下線、仕様書 §7 に値が直接書かれている）と
  data URI 内の色（セレクトの矢印）。

## 仕様書の値をそのまま使うための小技

| 仕様書の指定 | 書き方 |
|---|---|
| `border: 0.5px solid` | `border-[0.5px]`（Tailwind の `border` は 1px なので使わない） |
| 角丸 7px / 10px / 20px | `rounded-[7px]` 等の任意値 |
| パディング 9px 22px | `px-[22px] py-[9px]` |
| フォントサイズ | `text-xs`(10) / `text-sm`(11) / `text-md`(12) / `text-base`(13) / `text-lg`(14) / `text-xl`(15) / `text-2xl`(16) / `text-score`(26)。**Tailwind 標準とは値が異なる** |
| トランジション 120ms | `transition-colors duration-[120ms]` |

## 刺し色の使い方（仕様書 §1.2）

赤・アンバー・緑・青・楽天オレンジは用途固定。新しい部品で「目立たせたい」ときも
白系（`text-text-primary` / `bg-bg-btn`）で表現する。NEW バッジをグレー＋白文字に
したのはこの原則のため。

## ブレークポイント

Tailwind 標準の `md:`（768px）が共通 ページレイアウト 仕様書 §2 の PC/モバイル境界と
一致するため、独自のブレークポイントは定義しない。`md:` = PC、無印 = モバイル。

## 挙動はヘッドレスUI、見た目はトークン

モーダル・ドロワー・ドロップダウン・タブ・トーストは Radix UI Primitives のラッパー
（`components/ui/`）を通して使う。ページ側で Radix を直接 import しない。
完成品UIライブラリ（HeroUI / Mantine 等）はフロントには入れない（ユーザー決定）。
