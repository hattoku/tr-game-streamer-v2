# CSSグリッドのmin-width対策

`grid-template-columns`に`fr`単位（例: `md:grid-cols-[62fr_38fr]`）を使っていても、**グリッドアイテムの
`min-width`初期値は`auto`**（内容の最小コンテンツ幅）になる。子孫要素にどれだけ`line-clamp`や`truncate`で
折り返し・省略の制約を書いても、そのグリッドアイテム自身に`min-width: 0`（Tailwindの`min-w-0`）が
無ければ、内容の最小幅がトラック幅を押し広げ、ページ全体が横方向にオーバーフローする。

## 発生条件

- 特定の幅（[[2026-09-15-phase3-step5-finish]]では768px）でだけ顕在化しやすい。トラックへの割当幅が
  内容の最小幅に近いほど問題が起きやすく、十分広い幅（例1600px）や1カラムに切り替わる幅（例767px）
  では気づかれないまま残ることがある
- 長いテキスト（動画タイトル等の実データ）を含むリスト・カードをグリッドの列として配置する場合に起きやすい

## 対策

グリッドコンテナの**直下の子要素**（実際にグリッドアイテムとして扱われる要素）に`min-w-0`を付ける。
ネストしたグリッド（例: シアターモード時に列内がさらに2カラムグリッドになる構成）では、その内側の
グリッドの子要素にも同様に必要。

## 実例

`app/(main)/playlists/[playlistId]/page.tsx`の`md:grid-cols-[62fr_38fr]`（通常時2箇所＋シアターモード時の
ネストしたグリッド1箇所）。[[2026-09-15-phase3-step5-finish]]で768px時のオーバーフローとして発見・修正。
